**熔断器（Circuit Breaker）** 是一种用于提升系统稳定性和容错能力的机制。它的核心作用是：**防止系统在调用失败时无限制地重试，避免故障蔓延，保护系统其他部分正常运行。**

# 熔断器的三种状态

熔断器就像电路开关，有三种典型状态：

| 状态                 | 含义                                   |
| ------------------ | ------------------------------------ |
| **关闭（Closed）**     | 正常调用下游服务，即使有失败，也只记录失败次数。             |
| **开启（Open）**       | 达到失败阈值后，熔断器“断开电路”，不再调用下游服务，直接返回错误。   |
| **半开启（Half-Open）** | 在一段时间后允许部分请求试探性地调用下游服务，如果成功就恢复为关闭状态。 |
# 常见熔断器的使用

## `gobreaker`

安装： `go get github.com/sony/gobreaker`

```go
  st := gobreaker.Settings{
    Name:        "test breaker",
    MaxRequests: 3,
    Interval:    10 * time.Second,
    Timeout:     5 * time.Second,
    ReadyToTrip: func(counts gobreaker.Counts) bool {
      failRequestRate := float64(counts.TotalFailures) / float64(counts.Requests)
      return counts.Requests >= 5 || failRequestRate > 0.6
    },
  }
  cb := gobreaker.NewCircuitBreaker(st)
```

**代码解释**：
- **`Name`** 给熔断器一个名字，便于日志记录或调试。
- **`MaxRequests`** 熔断器在**半开启（Half-Open）状态**下，允许的“试探性请求”数量。只有都请求成功了，熔断器才会恢复到关闭状态
- **`Interval`** 统计窗口周期。每隔这个时间，会重置一次请求和失败计数（`Counts`）。只有在关闭状态才起效。类似于**固定窗口算法**的窗口大小。
- **`Timeout`** 熔断器进入**开启（Open）状态**后的持续时间。超过这个时间，会转为半开启状态，允许“试探性请求”执行。
- **`ReadyToTrip`** 判断熔断器**开启**的条件

# 简单熔断器的实现

```go
type State int

var (
  ErrCirclebreakerOpen = errors.New("circle breaker is open")
)

const (
  Close State = iota
  Open
  HalfOpen
)

type Option func(*CircuitBreaker)

type CircuitBreaker struct {
  Name           string
  state          State
  successRequest int
  failRequest    int
  failureThresh  int           //  The number of consecutive failure required to switch to the open state.
  successThresh  int           // The number of consecutive successes required to switch to the close state.
  timeout        time.Duration // duration of open
  lastFailTime   time.Time
  mu             sync.Mutex
}

func WithTimeout(timeout time.Duration) Option {
  return func(cb *CircuitBreaker) {
    cb.timeout = timeout
  }
}

func NewCircuitBreaker(successThresh int, failureThresh int, opts ...Option) *CircuitBreaker {
  b := &CircuitBreaker{
    state:          Close,
    successRequest: 0,
    failRequest:    0,
    successThresh:  successThresh,
    failureThresh:  failureThresh,
    timeout:        time.Minute,
  }

  for _, opt := range opts {
    opt(b)
  }
  
  return b
}

func (cb *CircuitBreaker) Execute(fn func() (any, error)) (any, error) {
  // check state
  cb.mu.Lock()
  switch cb.state {
  case Open:
    if time.Since(cb.lastFailTime) > cb.timeout {
      cb.state = HalfOpen
      cb.failRequest = 0
      cb.successRequest = 0
    } else {
      cb.mu.Unlock()
      return nil, ErrCirclebreakerOpen
    }
  case Close:
  case HalfOpen:
  }
  cb.mu.Unlock()
  
  res, err := fn()

  cb.mu.Lock()
  defer cb.mu.Unlock()

  if err != nil {
    cb.lastFailTime = time.Now()
    cb.failRequest += 1
    switch cb.state {
    case HalfOpen:
      cb.state = Open
    case Close:
      if cb.failRequest >= cb.failureThresh {
        cb.state = Open
        cb.successRequest = 0
        cb.failRequest = 0
      }
    }
    return nil, err
  } else {
    cb.successRequest += 1
    switch cb.state {
    case HalfOpen:
      if cb.successRequest >= cb.successThresh {
        cb.state = Close
      }
    case Close:
      cb.failRequest = 0
    }
    return res, nil
  }
}
```
