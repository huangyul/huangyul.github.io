# 令牌桶限流器

## 核心要点

- **固定速率生成令牌**：  
    每秒生成 `rate` 个令牌，存入一个最大容量为 `capacity` 的桶中。
    
- **按需消耗令牌**：  
    每次请求需要消耗 `requested` 个令牌，只有桶中令牌足够才允许通过。
    
- **时间驱动补充令牌**：  
    每次请求时，根据距上次请求的时间差 `delta` 来补充新令牌：  
    `current_tokens + delta * rate`，最多补到 `capacity`。
    
- **允许 or 拒绝请求**：  
    如果补充后的令牌 ≥ 请求所需，则允许，并扣除对应数量；否则拒绝。
    
- **Redis 持久化状态**：  
    当前令牌数和上次刷新时间存储在 Redis 中，使用 `setex` 设置过期时间自动清理。

## `lua` 脚本实现

```lua
local rate = tonumber(ARGV[1])
local capacity = tonumber(ARGV[2])
local now = tonumber(ARGV[3])
local requested = tonumber(ARGV[4])

local fill_timed = capacity / rate
local ttl = math.floor(fill_timed * 2)
local current_tokens = tonumber(redis.call("get", KEYS[1]))
if current_tokens == nil then
    current_tokens = capacity
end

local last_refresh = tonumber(redis.call("get", KEYS[2]))
if last_refresh == nil then
    last_refresh = 0
end

local delta = math.max(0, now - last_refresh)
local filled_tokens = math.min(capacity, current_tokens + (delta * rate))
local allowed = filled_tokens >= requested
local now_tokens = filled_tokens
  
if allowed then
    now_tokens = filled_tokens - requested
end

redis.call("setex", KEYS[1], ttl, now_tokens)
redis.call("setex", KEYS[2], ttl, now)

return allowed
```

# 固定窗口限流

## 核心要点

1. **限流逻辑基于时间窗口**
    
    - 使用固定长度的时间窗口（例如 60 秒），在窗口内限制请求次数。
        
2. **计数器存储在 Redis 中**
    
    - 利用 Redis 的原子操作 `INCRBY` 对某个 key 进行计数。
        
3. **首次访问时设置过期时间**
    
    - 当某个 key 第一次被访问时（即计数变为 1），使用 `EXPIRE` 设置窗口长度。
        
4. **判断请求是否超过限制**
    
    - 如果当前计数（`current`）小于或等于设定的限制值（`limit`），则允许请求。
