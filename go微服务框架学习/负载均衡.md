## 轮询均衡器

### 原理

负载均衡器保留一个下标值，每次返回下一个下标的服务

### 代码实现

```go
type RoundRobin[T any] struct {
  servers []T
  idx     int
  mu      sync.Mutex
}

  

func NewRoundRobin[T any](servers []T) *RoundRobin[T] {
  return &RoundRobin[T]{
    servers: servers,
    idx:     -1,
  }
}

func (rr *RoundRobin[T]) Next() T {
  rr.mu.Lock()
  defer rr.mu.Unlock()
  
  rr.idx = (rr.idx + 1) % len(rr.servers)
  return rr.servers[rr.idx]
}
```

## 加权轮询（WRR）

#### 原理

加权轮询（WRR）是 Round-Robin 的增强版，每台机器有一个 **权重值 weight**，表示它能承担的负载。

实现思路是：

- 为每个服务器维护：`currentWeight` 和 `weight`
    
- 每次选择 `currentWeight` 最大的那台服务器。
    
- 然后将该服务器的 `currentWeight` 减去总权重，所有服务器 `currentWeight += weight`。

#### 代码实现

```go
type Server[T any] struct {
  Target        T
  Weight        int
  CurrentWeight int
}

  

type WRR[T any] struct {
  Servers     []*Server[T]
  TotalWeight int
  mu          sync.Mutex
}

  

func NewWRR[T any]() *WRR[T] {
  return &WRR[T]{
    TotalWeight: 0,
  }
}

  

func (rr *WRR[T]) Add(target T, weight int) {
  if weight <= 0 {
    return
  }

  rr.mu.Lock()
  defer rr.mu.Unlock()

  rr.Servers = append(rr.Servers, &Server[T]{
    Target:        target,
    Weight:        weight,
    CurrentWeight: 0,
  })
  rr.TotalWeight += weight
}

  

func (rr *WRR[T]) Next() T {
  var zero T
  if len(rr.Servers) == 0 {
    return zero
  }

  var best *Server[T]
  for _, s := range rr.Servers {
    s.CurrentWeight += s.Weight // 每次轮询先加自己的 weight
    if best == nil || best.CurrentWeight < s.CurrentWeight {
      best = s
    }
  }
  best.CurrentWeight -= rr.TotalWeight // 最终选中后减去总权重（防止一直被选中）
  return best.Target

}
```
