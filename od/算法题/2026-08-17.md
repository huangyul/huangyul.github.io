#### 1. [739] 每日温度（Daily Temperatures）

- **核心分类**：单调栈（Monotonic Stack） / 寻找下一个更大元素（Next Greater Element）
    
- **生活化比喻**：**“排队等大哥” / “踢馆”**
    
    - 矮个子排队（栈内元素单调递减）。
        
    - 遇到更高的新人进场时，队尾比他矮的人逐个被“解脱/踢走”（出栈），并记录相隔天数。
        
    - 新人把能打赢的全部出栈后，自己入栈等待未来的“大哥”。
        
- **核心盲点与技巧**：
    
    - **存下标而非数值**：计算天数差必须依赖索引；通过 `temperatures[stack[top]]` 随时可查温度。
        
    - **单调栈 vs 哈希桶**：哈希桶是特定整数范围（$[30, 100]$）下的逆向查找奇技淫巧，单调栈才是通用的 $O(N)$ 标准解法。
        
- **Go 核心模板**：
    
    Go
    
    ```
    stack := make([]int, 0, n)
    for currDay, currTemp := range temperatures {
        for len(stack) > 0 && currTemp > temperatures[stack[len(stack)-1]] {
            prevDay := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            ans[prevDay] = currDay - prevDay
        }
        stack = append(stack, currDay)
    }
    ```
    

#### 2. [226] 翻转二叉树（Invert Binary Tree）

- **核心分类**：树的递归遍历 / 镜像变换
    
- **生活化比喻**：**“照镜子”**
    
    - 每个节点互换左右手，并让两只手各自管辖的子树也照镜子。
        
- **核心盲点与易错点**：
    
    - **递归基必须且仅为 `root == nil`**：千万不能写 `if root.Left == nil || root.Right == nil`。因为只有单侧孩子的节点也必须把单侧子树翻转到另一侧，写多了判空会导致单侧节点被漏掉。
        
- **Go 核心模板**：
    
    Go
    
    ```
    func invertTree(root *TreeNode) *TreeNode {
        if root == nil {
            return nil
        }
        root.Left, root.Right = invertTree(root.Right), invertTree(root.Left)
        return root
    }
    ```

# 3. 221. 最大正方形 (Maximal Square)

### 一、 核心直觉与物理模型

- **模型比喻**：**三人合力撑起大遮阳棚（木桶短板效应）**
    
- **核心机制**：
    
    - 将网格每个格子作为正方形的**右下角**顶点。
        
    - 要想扩展成边长加 1 的更大正方形，必须同时依赖**左方**、**上方**和**左上方**三个邻居撑起的保护伞。
        
    - 最终能撑起的最大正方形边长受限于**最弱的短板**（三者的最小值），否则内部或边缘会出现空洞（0）。
        

### 二、 核心算法推导

- **状态定义**：
    
    $dp[i][j]$ 表示以坐标 $(i, j)$ 为**右下角**的全 1 最大正方形的**边长**。
    
- **状态转移方程**：
    
    $$dp[i][j] = \begin{cases} 0, & \text{if } matrix[i][j] = '0' \\ 1, & \text{if } i = 0 \text{ or } j = 0 \\ \min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1, & \text{if } matrix[i][j] = '1' \end{cases}$$
    
- **最终答案**：
    
    $$\text{MaxArea} = (\max_{i, j} dp[i][j])^2$$
    

### 三、 盲点与避坑指南

1. **为什么必须取三个方向的最小值？**
    
    - 若只看左侧和上方，中间（左上方）若为 0，会导致正方形内部空心。取 $\min(\text{左}, \text{上}, \text{左上})$ 在几何上严格确保了**左侧边缘、上方边缘以及内部实心区域**全为 1。
        
2. **存“边长”而非“面积”**：
    
    - 边长满足简单的递增线性递推关系（$+1$），直接记录面积会破坏相邻子结构的状态转移规律。
        

### 四、 代码模板与时空复杂度

#### 1. 二维标准实现 (Go)

Go

```
func maximalSquare(matrix [][]byte) int {
    if len(matrix) == 0 || len(matrix[0]) == 0 {
        return 0
    }
    m, n := len(matrix), len(matrix[0])
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, n)
    }

    maxSide := 0
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if matrix[i][j] == '1' {
                if i == 0 || j == 0 {
                    dp[i][j] = 1
                } else {
                    dp[i][j] = min(dp[i-1][j], min(dp[i][j-1], dp[i-1][j-1])) + 1
                }
                if dp[i][j] > maxSide {
                    maxSide = dp[i][j]
                }
            }
        }
    }
    return maxSide * maxSide
}

func min(a, b int) int {
    if a < b { return a }
    return b
}
```


# 4. LeetCode 215. 数组中的第K个最大元素 (Kth Largest Element)

### 一、 核心直觉与物理模型

- **模型比喻**：**操场大点名与划定 VIP 专区**
    
- **核心机制**：
    
    - 选一个基准同学（Pivot）作为门槛，把所有人划分为**大数区（$\ge \text{Pivot}$）**和**小数区（$<\text{Pivot}$）**。
        
    - 分区结束后，基准同学的最终排名位置（索引 $p$）被彻底锁死。
        
    - **减治思想（扔掉一半）**：
        
        - 若基准恰好落在目标位置 $k-1$，直接命中答案。
            
        - 若基准位置靠后（$p > k-1$），说明目标在左半边，**右半边所有人直接淘汰**，缩小范围继续搜。
            
        - 若基准位置靠前（$p < k-1$），说明目标在右半边，**左半边所有人直接淘汰**。
            

### 二、 核心算法推导 (降序直觉模型)

- **目标索引对齐**：
    
    - 从大到小排列时，第 $k$ 个最大元素对应下标恰好为：
        
        $$\text{targetIndex} = k - 1$$
        
- **单向推铁门（Lomuto Partition）机制**：
    
    - 将基准值（Pivot）暂存在区间最右侧 `right`。
        
    - 指针 `i` 作为 **VIP 大数专区右边界（铁门）**，初始位于 `left`。
        
    - 指针 `j` 从 `left` 到 `right-1` 巡逻：
        
        - 遇小数（$<\text{Pivot}$）：跳过。
            
        - 遇大数（$\ge \text{Pivot}$）：与 `i` 位置交换并推进铁门（`i++`）。
            
    - 巡逻完毕后，将暂存在 `right` 的 Pivot 换回 `i` 位置完成归位。
        

### 三、 盲点与避坑指南

1. **升序 vs 降序的心智模型选择**：
    
    - **降序写法（推荐）**：`target = k - 1`，分区判断 `nums[j] >= pivot`（大数往前赶）。题目求“大”，代码顺势降序，直觉与数学下标完全吻合，避免 `len(nums) - k` 的 Off-by-one 换算错误。
        
    - **升序写法**：若分区将小数放左边（`nums[j] < pivot`），则目标下标必须转换为倒数第 $k$ 个（`target = len(nums) - k`）。
        
2. **为什么需要传入 `left` 与 `right`？**
    
    - 排除掉不需要的半区后，下次搜索的起点不一定是 `0`。`left` 既圈定了局部搜索区间，也**锁死并保护了左侧已经确定的前序大数区**不被破坏。
        
3. **避免极端用例退化为 $O(n^2)$**：
    
    - 必须避免固定选取最左/最右元素作为基准。优先选取**区间中点 `mid`** 或使用**随机交换**，破坏单调升序/降序用例的恶化结构。
        

### 四、 代码实现 (Go 终极干净版 - 降序 + 中点防退化)

Go

```
package main

func findKthLargest(nums []int, k int) int {
	// 降序排列下，第 k 大元素对应正数第 k-1 个位置
	targetIdx := k - 1
	left, right := 0, len(nums)-1

	for left <= right {
		pivotIdx := partition(nums, left, right)
		if pivotIdx == targetIdx {
			// 命中目标，直接返回
			return nums[pivotIdx]
		} else if pivotIdx > targetIdx {
			// 基准排在目标后面，目标在左半区，右半区全员排除
			right = pivotIdx - 1
		} else {
			// 基准排在目标前面，目标在右半区，左半区全员排除
			left = pivotIdx + 1
		}
	}

	return -1
}

// 降序 Partition：大数赶到左侧，返回基准最终下标
func partition(nums []int, left, right int) int {
	// 选取中点作为基准并暂存到最右侧，无需导包且防止有序数据退化
	mid := left + (right-left)/2
	nums[mid], nums[right] = nums[right], nums[mid]

	pivot := nums[right]
	i := left // i: VIP 大数专区的右边界

	// j 巡逻员：扫描 [left, right-1]
	for j := left; j < right; j++ {
		if nums[j] >= pivot {
			// 抓到大数，送入 VIP 区并右移铁门
			nums[i], nums[j] = nums[j], nums[i]
			i++
		}
	}

	// 裁判归位：把暂存在最右侧的 pivot 换到分界线 i 上
	nums[i], nums[right] = nums[right], nums[i]
	return i
}
```

- **时间复杂度**：
    
    - 平均时间复杂度：$O(n)$，每次排除一半数据，计算量为 $n + \frac{n}{2} + \frac{n}{4} + \dots \approx 2n$。
        
    - 最坏时间复杂度：$O(n^2)$（在中点选取优化下极难触发）。
        
- **空间复杂度**：$O(1)$，原地迭代交换，无额外内存及递归调用栈开销。
