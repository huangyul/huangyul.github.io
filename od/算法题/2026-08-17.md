#### 1. [739] 每日温度（Daily Temperatures）

- **核心分类**：单调栈（Monotonic Stack） / 寻找下一个更大元素（Next Greater Element）
    
- **生活化比喻**：**“排队等大哥” / “踢馆”**
    
    - 矮个子排队（栈内元素单调递减）。
        
    - 遇到更高的新人进场时，队尾比他矮的人逐个被“解脱/踢走”（出栈），并记录相隔天数。
        
    - 新人把能打赢的全部出栈后，自己入栈等待未来的“大哥”。
        
- **核心盲点与技巧**：
    
    - **存下标而非数值**：计算天数差必须依赖索引；通过 `temperatures[stack[top]]` 随时可查温度。
        
    - **单调栈 vs 哈希桶**：哈希桶是特定整数范围（$[30, 100]$）下的逆向查找奇技淫巧，单调栈才是通用的 $O(N)$ 标准解法。
        
- **Go 核心模板**：
    
    Go
    
    ```
    stack := make([]int, 0, n)
    for currDay, currTemp := range temperatures {
        for len(stack) > 0 && currTemp > temperatures[stack[len(stack)-1]] {
            prevDay := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            ans[prevDay] = currDay - prevDay
        }
        stack = append(stack, currDay)
    }
    ```
    

#### 2. [226] 翻转二叉树（Invert Binary Tree）

- **核心分类**：树的递归遍历 / 镜像变换
    
- **生活化比喻**：**“照镜子”**
    
    - 每个节点互换左右手，并让两只手各自管辖的子树也照镜子。
        
- **核心盲点与易错点**：
    
    - **递归基必须且仅为 `root == nil`**：千万不能写 `if root.Left == nil || root.Right == nil`。因为只有单侧孩子的节点也必须把单侧子树翻转到另一侧，写多了判空会导致单侧节点被漏掉。
        
- **Go 核心模板**：
    
    Go
    
    ```
    func invertTree(root *TreeNode) *TreeNode {
        if root == nil {
            return nil
        }
        root.Left, root.Right = invertTree(root.Right), invertTree(root.Left)
        return root
    }
    ```

# 3. 221. 最大正方形 (Maximal Square)

### 一、 核心直觉与物理模型

- **模型比喻**：**三人合力撑起大遮阳棚（木桶短板效应）**
    
- **核心机制**：
    
    - 将网格每个格子作为正方形的**右下角**顶点。
        
    - 要想扩展成边长加 1 的更大正方形，必须同时依赖**左方**、**上方**和**左上方**三个邻居撑起的保护伞。
        
    - 最终能撑起的最大正方形边长受限于**最弱的短板**（三者的最小值），否则内部或边缘会出现空洞（0）。
        

### 二、 核心算法推导

- **状态定义**：
    
    $dp[i][j]$ 表示以坐标 $(i, j)$ 为**右下角**的全 1 最大正方形的**边长**。
    
- **状态转移方程**：
    
    $$dp[i][j] = \begin{cases} 0, & \text{if } matrix[i][j] = '0' \\ 1, & \text{if } i = 0 \text{ or } j = 0 \\ \min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1, & \text{if } matrix[i][j] = '1' \end{cases}$$
    
- **最终答案**：
    
    $$\text{MaxArea} = (\max_{i, j} dp[i][j])^2$$
    

### 三、 盲点与避坑指南

1. **为什么必须取三个方向的最小值？**
    
    - 若只看左侧和上方，中间（左上方）若为 0，会导致正方形内部空心。取 $\min(\text{左}, \text{上}, \text{左上})$ 在几何上严格确保了**左侧边缘、上方边缘以及内部实心区域**全为 1。
        
2. **存“边长”而非“面积”**：
    
    - 边长满足简单的递增线性递推关系（$+1$），直接记录面积会破坏相邻子结构的状态转移规律。
        

### 四、 代码模板与时空复杂度

#### 1. 二维标准实现 (Go)

Go

```
func maximalSquare(matrix [][]byte) int {
    if len(matrix) == 0 || len(matrix[0]) == 0 {
        return 0
    }
    m, n := len(matrix), len(matrix[0])
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, n)
    }

    maxSide := 0
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if matrix[i][j] == '1' {
                if i == 0 || j == 0 {
                    dp[i][j] = 1
                } else {
                    dp[i][j] = min(dp[i-1][j], min(dp[i][j-1], dp[i-1][j-1])) + 1
                }
                if dp[i][j] > maxSide {
                    maxSide = dp[i][j]
                }
            }
        }
    }
    return maxSide * maxSide
}

func min(a, b int) int {
    if a < b { return a }
    return b
}
```
