
## 1. LeetCode 160. 相交链表

### 📋 题目描述

给你两个单链表的头节点 `headA` 和 `headB` ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在交点，返回 `nil` 。

- **示例 1**：
    
    - 输入：`listA = [4,1,8,4,5]`, `listB = [5,6,1,8,4,5]`
        
    - 输出：`Reference of the node with value = 8`
        
    - 解释：相交节点的值为 `8` （注意：不是值相等，而是内存物理地址/节点引用相同）。
        
- **重要约束**：
    
    - 题目数据保证整个链结构中不存在环。
        
    - 函数返回结果后，链表必须**保持其原始结构**。
        

### 核心思想：消除长度差（交换路线法）

- **突破口**：两条链表长度可能不一致，无法同步对齐。但设链表 A 独有长度 $a$，链表 B 独有长度 $b$，公共长度 $c$。
    
- **逻辑**：`pA` 走完 A 转去走 B，`pB` 走完 B 转去走 A。两者走过的总距离都是 $a + b + c$。当他们走到第二趟时，会在交点处**完美重合**；若不相交，则会在 `nil` 处重合退出。
    

### 复杂度

- **时间复杂度**：$\mathcal{O}(m + n)$
    
- **空间复杂度**：$\mathcal{O}(1)$
    

### Go 核心代码



```Go
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    if headA == nil || headB == nil {
        return nil
    }
    pA, pB := headA, headB
    
    // 两指针相等时退出（要么同指交点，要么同指 nil）
    for pA != pB {
        if pA == nil {
            pA = headB
        } else {
            pA = pA.Next
        }

        if pB == nil {
            pB = headA
        } else {
            pB = pB.Next
        }
    }
    return pA
}
```

## 2. LeetCode 206. 反转链表

### 📋 题目描述

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表头节点。

- **示例 1**：
    
    - 输入：`head = [1,2,3,4,5]`
        
    - 输出：`[5,4,3,2,1]`
        
- **示例 2**：
    
    - 输入：`head = [1,2]`
        
    - 输出：`[2,1]`
        

### 核心思想：三指针（找后路 $\rightarrow$ 掉车头 $\rightarrow$ 前人走 $\rightarrow$ 我跟上）

- **突破口**：单链表修改指向会导致后续节点丢失，必须提前记录下一个节点。
    
- **变量定义**：`prev`（前节点），`curr`（当前节点），`nextTemp`（临时保存的下个节点）。
    

### 复杂度

- **时间复杂度**：$\mathcal{O}(N)$
    
- **空间复杂度**：$\mathcal{O}(1)$
    

### Go 核心代码



```Go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head

    for curr != nil {
        nextTemp := curr.Next // 1. 找后路（保存下一个节点）
        curr.Next = prev      // 2. 掉车头（反转当前指针）
        prev = curr           // 3. 前人走（prev 向前一步）
        curr = nextTemp       // 4. 我跟上（curr 向前一步）
    }
    return prev // 新的头节点
}
```

## 3. LeetCode 234. 回文链表

### 📋 题目描述

给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

- **示例 1**：
    
    - 输入：`head = [1,2,2,1]`
        
    - 输出：`true`
        
- **示例 2**：
    
    - 输入：`head = [1,2]`
        
    - 输出：`false`
        
- **进阶要求**：你能否用 $\mathcal{O}(N)$ 时间复杂度和 $\mathcal{O}(1)$ 空间复杂度解决此题？
    

### 核心思想：快慢指针找中点 + 局部反转

- **突破口**：单链表无法像数组那样双指针从两端倒退对齐。
    
- **步骤**：
    
    1. 使用快慢指针（慢走 1 步，快走 2 步）定位链表中点。
        
    2. 调用 `reverseList` 反转后半段链表。
        
    3. 双指针分别从“原头节点”和“反转后的尾节点”同时同速对比。
        

### 复杂度

- **时间复杂度**：$\mathcal{O}(N)$
    
- **空间复杂度**：$\mathcal{O}(1)$
    

### Go 核心代码



```Go
func isPalindrome(head *ListNode) bool {
    if head == nil || head.Next == nil {
        return true
    }

    // 1. 快慢指针找中点
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }

    // 2. 反转后半段
    secondHalf := reverseList(slow)

    // 3. 两头对比
    p1, p2 := head, secondHalf
    isPal := true
    for p2 != nil {
        if p1.Val != p2.Val {
            isPal = false
            break
        }
        p1 = p1.Next
        p2 = p2.Next
    }
    return isPal
}
```

## 4. LeetCode 236. 二叉树的最近公共祖先

### 📋 题目描述

给定一个二叉树, 找到该树中两个指定节点 `p` 和 `q` 的最近公共祖先（LCA）。

> **最近公共祖先定义**：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

- **示例 1**：
    
    - 输入：`root = [3,5,1,6,2,0,8,null,null,7,4]`, `p = 5`, `q = 1`
        
    - 输出：`3` （节点 5 和节点 1 的最近公共祖先是 3）
        
- **示例 2**：
    
    - 输入：`root = [3,5,1,6,2,0,8,null,null,7,4]`, `p = 5`, `q = 4`
        
    - 输出：`5` （节点 5 和节点 4 的最近公共祖先是 5，因为一个节点可以是它自己的祖先）
        
- **重要约束**：
    
    - 所有 `Node.val` 互不相同。
        
    - `p` 和 `q` 均为不同节点，且均存在于给定的二叉树中。
        

### 核心思想：后序遍历自底向上（向上汇报机制）

- **突破口**：利用递归函数返回值代表“搜寻结果”，由子节点向父节点逐层传递。
    
- **汇报规则**：
    
    1. 当前节点为 `nil` 或目标节点 `p` / `q` 时，直接返回当前节点。
        
    2. 递归搜寻左右子树：`left` 与 `right`。
        
    3. **汇总**：
        
        - `left != nil && right != nil`：说明 $p$ 和 $q$ 在当前节点左右两侧汇合，当前节点即为 **最近公共祖先**。
            
        - 仅单侧有值：将非空的搜寻信号继续向上层汇报。
            
        - 两侧均为 `nil`：向上层汇报 `nil`。
            

### 复杂度

- **时间复杂度**：$\mathcal{O}(N)$
    
- **空间复杂度**：$\mathcal{O}(N)$（递归栈深度，平衡树时为 $\mathcal{O}(\log N)$）
    

### Go 核心代码



```Go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    // 1. 递归终止条件 / 碰触目标
    if root == nil || root == p || root == q {
        return root
    }

    // 2. 搜寻左右子树
    left := lowestCommonAncestor(root.Left, p, q)
    right := lowestCommonAncestor(root.Right, p, q)

    // 3. 根据汇报结果归并
    if left != nil && right != nil {
        return root // 两侧都有汇报，当前节点即为最近公共祖先
    }

    // 单侧有值向上透传，都无值返回 nil
    if left != nil {
        return left
    }
    return right
}
```
