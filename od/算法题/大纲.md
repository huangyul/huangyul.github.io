

## 二、 知识点考点频次与学习路径

> 说明：优先级别标记中，`★★★ 必会` 为核心重点，`★★ 重点` 次之，`★ 了解` / `可选` 补充提升。

### 1. 核心与必考知识点（高频/必会）
- **字符串处理**（`★★★ 必会`）：
  - **核心点**：字符遍历、分割、正则、HashMap 映射、协议解析。
  - **学习建议**：本考区第一关，优先掌握。
- **哈希表**（`★★★ 必会`）：
  - **核心点**：去重、频率统计、快速映射。
  - **学习建议**：本考区第一关，优先准备。
- **双指针 / 矩阵**（`★★★ 必会`）：
  - **核心点**：双指针遍历、二维矩阵扫描与转换。
  - **学习建议**：掌握基础技巧，提高编码熟练度。
- **栈 / 队列 / 单调栈**（`★★★ 必会`）：
  - **核心点**：LIFO/FIFO 模拟、撤销/重做（Undo/Redo）、单调栈找“下一个更大元素”。
  - **学习建议**：掌握基础及单调栈应用。
- **双指针 / 动态规划 / 贪心**（`★★★ 必会`）：
  - **核心点**：基础双指针、滑动窗口、贪心组合、状态转移。
  - **学习建议**：基础贪心/双指针的权重计算与优化。

### 2. 重要与进阶知识点（中高频/重点）
- **单链表**（`★★ 重点`）：
  - **核心点**：链表操作、双向链表历史记录管理。
  - **学习建议**：复杂数据结构变体需掌握。
- **BFS / 广搜**（`★★ 重点`）：
  - **核心点**：图与网格图的广度优先搜索、最短路径。
  - **学习建议**：与 DFS 互补掌握。
- **树 / 二叉树**（`★★ 重点`）：
  - **核心点**：递归遍历、序列化与反序列化、二叉树匹配。
  - **学习建议**：注重递归思维与场景应用。
- **滑动窗口**（`★★ 重点`）：
  - **核心点**：双指针维护窗口、最长/最短无重复子串。
  - **学习建议**：双指针进阶应用。
- **图论（DFS / BFS / 拓扑排序）**（`★★ 重点`）：
  - **核心点**：可达性判定、拓扑排序依赖构建（回溯输出全排列）。
  - **学习建议**：图论基础与建图。
- **动态规划 (DP)**（`★★ 重点`）：
  - **核心点**：二维 DP（最短路径/编辑距离变种）、背包问题（完全背包）、网格 DP。
  - **学习建议**：二星题重中之重，掌握状态转移方程。
- **自定义排序（多级排序）**（`★★ 重点`）：
  - **核心点**：自定义 Comparator、多字段条件排序。
  - **学习建议**：一星/二星均高频，必熟练。

### 3. 基础与辅助知识点（了解/可选）
- **位运算**（`★ 了解`）：
  - **核心点**：二进制位控制、等距二进制判定、进制转换。
- **二分查找**（`★ 了解`）：
  - **核心点**：有序数组检索、边界查找。
- **贪心**（`★ 了解`）：
  - **核心点**：区间调度、最大不重叠区间。
- **并查集**（`★ 了解`）：
  - **核心点**：连通性判定与集合合并。
- **堆 / 优先队列**（`可选`）：
  - **核心点**：Top-K 问题、优先队列维护。
- **滑动窗口（补充）**（`可选`）：
  - **核心点**：固定/可变窗口计算。
- **对重叠区间**（`★★ 重点`）：
  - **核心点**：区间合并、重叠/覆盖判定。

## 四、 真实机考题型与案例分类汇总

### 1. 一星题典型案例（侧重基础编码、数据结构与模拟）
1. **字符串与协议解析**：
   - *关键数据查询（十六进制协议解析）*、*失灵的键盘*、*IP 地址分类识别*、*小学英语老师批改作文（带忽略大小写/去空格）*、*查找能被整除的最大整数*。
2. **哈希表与统计**：
   - *准备生日礼物（覆盖重复数据）*、*日志文件异常检测（频次排序）*、*配置操作失败数量统计*、*文档特征提取（交集最小值）*。
3. **栈/队列与历史管理**：
   - *简单文本编辑器（撤销/重做）*、*操作历史管理器*、*端口流量统计（单调栈）*、*数据包优先级窗口查找*。
4. **自定义多级排序**：
   - *分辨率排序（清晰度 > 面积 > 宽）*。
5. **模拟与贪心/位运算**：
   - *网上商城优惠活动（多级优惠组合）*、*8位 LED 控制器（位运算）*、*设备开机时段分类（时间区间）*、*最大化游戏试玩资格分发（区间调度）*。

### 2. 二星题典型案例（侧重 DP、图论与复杂模拟）
1. **动态规划（DP）**：
   - *两个字符串间的最短路径问题*（二维 DP，对角线/水平/垂直转移）。
   - *模型准确率和延迟*（完全背包，限制总延迟与数量选最大价值）。
2. **图论与搜索（DFS/BFS/拓扑）**：
   - *勇攀数字高峰*（DFS 回溯求严格递增路径数）。
   - *直捣黄龙*（BFS 网格最短路径计数 + 避开哨兵）。
   - *水站孤立站判定*（BFS/DFS 图遍历连通性）。
   - *项目模块依赖构建顺序*（拓扑排序 + 回溯输出所有字典序排列）。
3. **复杂逻辑模拟与优化**：
   - *小猫钓鱼纸牌游戏*（双端队列/栈 + 复杂收牌逻辑模拟）。
   - *寻找重复子树*（树的序列化 + 哈希 + 自定义排序）。
   - *循环内存存取计算*（环形缓冲区 + 指针对齐计算）。
   - *数据包优先级窗口查找（二星大数据量版）*（数据量至 $10^6$，需 $O(n)$ 单调栈优化）。
