

## 二、 知识点考点频次与学习路径

> 说明：优先级别标记中，`★★★ 必会` 为核心重点，`★★ 重点` 次之，`★ 了解` / `可选` 补充提升。

### 1. 核心与必考知识点（高频/必会）
- **字符串处理**（`★★★ 必会`）：
  - **核心点**：字符遍历、分割、正则、HashMap 映射、协议解析。
  - **学习建议**：本考区第一关，优先掌握。
- **哈希表**（`★★★ 必会`）：
  - **核心点**：去重、频率统计、快速映射。
  - **学习建议**：本考区第一关，优先准备。
- **双指针 / 矩阵**（`★★★ 必会`）：
  - **核心点**：双指针遍历、二维矩阵扫描与转换。
  - **学习建议**：掌握基础技巧，提高编码熟练度。
- **栈 / 队列 / 单调栈**（`★★★ 必会`）：
  - **核心点**：LIFO/FIFO 模拟、撤销/重做（Undo/Redo）、单调栈找“下一个更大元素”。
  - **学习建议**：掌握基础及单调栈应用。
- **双指针 / 动态规划 / 贪心**（`★★★ 必会`）：
  - **核心点**：基础双指针、滑动窗口、贪心组合、状态转移。
  - **学习建议**：基础贪心/双指针的权重计算与优化。

### 2. 重要与进阶知识点（中高频/重点）
- **单链表**（`★★ 重点`）：
  - **核心点**：链表操作、双向链表历史记录管理。
  - **学习建议**：复杂数据结构变体需掌握。
- **BFS / 广搜**（`★★ 重点`）：
  - **核心点**：图与网格图的广度优先搜索、最短路径。
  - **学习建议**：与 DFS 互补掌握。
- **树 / 二叉树**（`★★ 重点`）：
  - **核心点**：递归遍历、序列化与反序列化、二叉树匹配。
  - **学习建议**：注重递归思维与场景应用。
- **滑动窗口**（`★★ 重点`）：
  - **核心点**：双指针维护窗口、最长/最短无重复子串。
  - **学习建议**：双指针进阶应用。
- **图论（DFS / BFS / 拓扑排序）**（`★★ 重点`）：
  - **核心点**：可达性判定、拓扑排序依赖构建（回溯输出全排列）。
  - **学习建议**：图论基础与建图。
- **动态规划 (DP)**（`★★ 重点`）：
  - **核心点**：二维 DP（最短路径/编辑距离变种）、背包问题（完全背包）、网格 DP。
  - **学习建议**：二星题重中之重，掌握状态转移方程。
- **自定义排序（多级排序）**（`★★ 重点`）：
  - **核心点**：自定义 Comparator、多字段条件排序。
  - **学习建议**：一星/二星均高频，必熟练。
