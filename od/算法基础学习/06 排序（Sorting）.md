
排序是算法机试与面试中**出现频次最高、与其它算法结合最紧密**的基石模块。在机考实战中，重点不是背诵手写快排，而是**熟练运用标准库、设计多维比较规则、甄别特殊场景（如 Top-K、计数优化）**。

## 一、核心指标与考点分类

### 1. 核心维度

- **时间复杂度**：比较类排序理论下界为 $O(N \log N)$；小数据规模（$N \le 16$）插入排序更优；特殊范围整数可用非比较排序做到 $O(N)$。
    
- **空间复杂度**：原地排序开销为 $O(1) \sim O(\log N)$；归并排序为 $O(N)$。
    
- **稳定性（Stability）**：相同键值的元素排序后是否保持原有相对次序。机试中若包含“按输入顺序输出相同项”**，必须使用**稳定排序。
    

### 2. 算法速查表

|**算法**|**平均时间**|**最坏时间**|**空间**|**稳定性**|**核心思想 / 典型应用**|
|---|---|---|---|---|---|
|**快速排序**|$O(N \log N)$|$O(N^2)$|$O(\log N)$|不稳定|分治法 + Partition（衍生出快速选择 QuickSelect）|
|**归并排序**|$O(N \log N)$|$O(N \log N)$|$O(N)$|**稳定**|分治法 + 双指针合并（常用于**链表排序**、**逆序对统计**）|
|**堆排序**|$O(N \log N)$|$O(N \log N)$|$O(1)$|不稳定|堆化下沉（衍生出静态/动态 **Top-K**、对顶堆）|
|**插入排序**|$O(N^2)$|$O(N^2)$|$O(1)$|**稳定**|增量构造有序表（基本有序或小规模序列极快）|
|**计数/桶排序**|$O(N + K)$|$O(N + K)$|$O(K)$|**稳定**|值映射到桶下标（突破比较限制，$N$ 极大且数值范围 $K$ 小）|

## 二、机试标准库高频实战（Go 示例）

在现代 Go（Go 1.21+）中，优先使用标准库 `slices` 包，性能优于传统基于反射的 `sort.Slice`。

### 1. 基础基础与降序


```Go
import "slices"

// 基础升序
slices.Sort(nums)

// 基础降序（利用自定义比较函数）
slices.SortFunc(nums, func(a, b int) int {
    return b - a // >0 时交换，实现降序
})
```

### 2. 多维度 / 复合字段排序（最核心考点）

> **题目特征**：按分数从高到低；若分数相同，按名字字典序升序；若还相同，按原输入相对顺序保留。

```Go
type Student struct {
    Name  string
    Score int
}

// 稳定排序：确保同优先级元素相对位置不变
slices.SortStableFunc(students, func(a, b Student) int {
    if a.Score != b.Score {
        return b.Score - a.Score // 1. 分数降序
    }
    // 2. 名字升序
    if a.Name < b.Name {
        return -1
    } else if a.Name > b.Name {
        return 1
    }
    return 0
})
```

### 3. 间接排序（保留原始下标）

> **题目特征**：需要根据数值大小排序，但最终需要输出原始元素对应的索引下标。


```Go
indices := make([]int, n)
for i := range indices {
    indices[i] = i
}

// 对索引进行排序
slices.SortFunc(indices, func(i, j int) int {
    if nums[i] != nums[j] {
        return nums[i] - nums[j]
    }
    return i - j // 次级条件：按下标升序
})
```

### 4. 排序后配合二分查找

```Go
// slices.BinarySearch 要求切片已升序排好
idx, found := slices.BinarySearch(sortedNums, target)
if found {
    // 找到了 target，其下标为 idx
} else {
    // 未找到，idx 为 target 应该插入的位置（满足有序性）
}
```

## 三、四大进阶考点与解题套路

### 1. 区间重叠 / 区间贪心（机试第一高频）

- **套路**：通常按**左端点升序**排序；若左端点相同，按右端点排序。
    
- **合并区间模板**：
    ```Go
    slices.SortFunc(intervals, func(a, b []int) int {
        return a[0] - b[0]
    })
    res := [][]int{intervals[0]}
    for i := 1; i < len(intervals); i++ {
        last := &res[len(res)-1]
        cur := intervals[i]
        if cur[0] <= (*last)[1] { // 重叠，扩展右边界
            (*last)[1] = max((*last)[1], cur[1])
        } else {
            res = append(res, cur)
        }
    }
    ```
    

### 2. 寻找第 K 大 / 前 K 个元素（Top-K）

- **错误做法**：对整个长度为 $N$ 的数组全量排序，时间复杂度 $O(N \log N)$（当 $N$ 极大、$K$ 很小时易超时）。
    
- **标准解法**：
    
    - **小顶堆维护前 K 大**：复杂度 $O(N \log K)$。
        
    - **快速选择（QuickSelect）**：平均时间复杂度 $O(N)$。
        

### 3. 计数排序优化（针对稀疏分布或固定取值）

- **题目特征**：$N \ge 10^5$，但元素范围限制在特定区间（如年龄 $0 \sim 120$、字符 `'a' \sim 'z'`、成绩 $0 \sim 100$）。
    
- **解法**：直接使用固定大小数组充当哈希桶进行频次累加，随后顺序还原，复杂度 $O(N + C)$，击败所有基于比较的算法。
    

### 4. 逆序对 / 相对偏序统计

- **题目特征**：求数组中有多少对 $(i, j)$ 满足 $i < j$ 且 $nums[i] > nums[j]$。
    
- **解法**：无法直接使用标准库，需要借用**归并排序的 merge 阶段**（当右侧元素先落入辅助数组时，左侧剩余未落入元素均构成逆序对）或树状数组（Fenwick Tree）在 $O(N \log N)$ 时间内完成统计。


### 5. 机考中应对“排序”的最小完备工具包

在实际机试中，建议将技能树补全为以下 4 样东西，即可做到全面覆盖：

1. **`slices.Sort`**：纯数字、字符串升序排列。
    
2. **`slices.SortFunc`**：自定义规则（降序、多字段结构体、索引数组排序）。
    
3. **`slices.SortStableFunc`**：有“按原顺序保留”要求的自定义排序。
    
4. **`container/heap` 模板**：应对 Top-K 和对顶堆问题（提前准备好堆的 5 个方法模板）。
    

## 四、机试避坑 CheckList

1. **审题看稳定性**：输入出现“平局按原始顺序输出”、“相同权重先来后到”时，务必切换为 `SortStable` 类 API。
    
2. **防整数减法溢出**：在比较函数中写 `a - b` 简化比较时，注意 `a` 为极大正数、`b` 为极小负数可能引发的整数溢出。在严谨场景建议使用明确的三分支比较（`<` 返回 `-1`，`>` 返回 `1`，`==` 返回 `0`）。
    
3. **识别数据流场景**：如果是**动态连续插入 + 动态查询排序指标（如中位数）**，绝不能每次插入后调一次排序（复杂度退化到 $O(N^2 \log N)$），应使用**对顶堆**维护。
