# 一、队列 Queue

## 1. 什么是队列

队列（Queue）是一种遵循 **FIFO（First In First Out）** 原则的数据结构。

即：

```text
先进先出
```

例如：

```text
入队：

A -> B -> C

出队顺序：

A -> B -> C
```

和栈（Stack）相反：

```text
栈：LIFO（后进先出）
队列：FIFO（先进先出）
```

---

## 2. Go实现队列

Go没有内置Queue。

通常使用slice模拟：

```go
q := []int{}
```

### 入队

```go
q = append(q, 10)
```

### 出队

```go
x := q[0]
q = q[1:]
```

示例：

```go
q := []int{}

q = append(q, 1)
q = append(q, 2)
q = append(q, 3)

x := q[0]
q = q[1:]
```

结果：

```text
x = 1

q = [2,3]
```

# 二、例题1：933. 最近的请求次数

## 题目

实现：

```go
ping(t)
```

返回：

```text
[t-3000, t]
```

区间内请求数量。

例如：

```text
ping(1)     -> 1
ping(100)   -> 2
ping(3001)  -> 3
ping(3002)  -> 3
```

---

## 思路

维护一个队列：

```text
队尾：加入新请求

队头：删除过期请求
```

因为：

```text
时间严格递增
```

所以：

```text
过期元素永远不会再次有效
```

直接从队头删除即可。

---

## Go代码

```go
type RecentCounter struct {
    queue []int
}

func Constructor() RecentCounter {
    return RecentCounter{}
}

func (r *RecentCounter) Ping(t int) int {

    r.queue = append(r.queue, t)

    for r.queue[0] < t-3000 {
        r.queue = r.queue[1:]
    }

    return len(r.queue)
}
```

---

## 核心思想

```text
队尾加入新数据

队头删除失效数据
```

属于：

```text
队列维护窗口
```

# 三、BFS与队列

## BFS是什么

BFS：

```text
Breadth First Search
广度优先搜索
```

特点：

```text
一层一层向外扩散
```

例如：

```text
       1
      / \
     2   3
    / \   \
   4   5   6
```

遍历顺序：

```text
1

2 3

4 5 6
```

即：

```text
按层遍历
```

---

## BFS为什么必须用队列

因为：

```text
先发现的节点

先处理
```

天然符合：

```text
FIFO
```

所以：

```text
BFS = Queue
```

---

# BFS模板

```go
queue := []Node{start}

for len(queue) > 0 {

    size := len(queue)

    for i := 0; i < size; i++ {

        cur := queue[0]
        queue = queue[1:]

        // 处理当前节点

        // 下一层加入队列
    }
}
```

重点：

```go
size := len(queue)
```

表示：

```text
当前层节点数量
```

# 四、例题2：102. 二叉树层序遍历

## 题目

输入：

```text
       3
      / \
     9   20
        / \
       15  7
```

输出：

```text
[
 [3],
 [9,20],
 [15,7]
]
```

---

## 思路

典型BFS。

使用队列：

```text
第一层
↓

第二层
↓

第三层
```

逐层遍历。

---

## Go代码

```go
func levelOrder(root *TreeNode) [][]int {

    if root == nil {
        return nil
    }

    queue := []*TreeNode{root}

    ans := [][]int{}

    for len(queue) > 0 {

        size := len(queue)

        level := []int{}

        for i := 0; i < size; i++ {

            node := queue[0]
            queue = queue[1:]

            level = append(level, node.Val)

            if node.Left != nil {
                queue = append(queue, node.Left)
            }

            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        ans = append(ans, level)
    }

    return ans
}
```

---

## 核心思想

```text
队列保存当前层节点

size控制层级边界
```

记忆：

```text
层序遍历 = BFS = Queue
```

# 五、双端队列 Deque

普通队列：

```text
只能：

队尾入
队头出
```

双端队列：

```text
队头可进可出

队尾可进可出
```

结构：

```text
←→ deque ←→
```

用于：

```text
单调队列
```

# 六、单调队列 Monotonic Queue

## 为什么需要单调队列

题目：

```text
滑动窗口最大值
```

例如：

```text
[1,3,-1]
```

最大：

```text
3
```

继续滑动：

```text
[3,-1,-3]
```

最大：

```text
3
```

要求：

```text
快速得到窗口最大值
```

---

## 核心思想

维护一个：

```text
单调递减队列
```

例如：

```text
5
↓
3
↓
1
```

特点：

```text
队头永远最大
```

因此：

```text
deque[0]
```

就是窗口最大值。

---

## 两个关键操作

### 1. 删除过期元素

窗口滑动时：

```go
if deque[0] <= i-k {
    deque = deque[1:]
}
```

表示：

```text
离开窗口
```

必须删除。

---

### 2. 删除无竞争力元素

当前元素：

```text
5
```

队尾：

```text
3
```

因为：

```text
5 > 3
```

那么：

```text
3以后永远不可能成为最大值
```

删除：

```go
for len(deque) > 0 &&
    nums[deque[len(deque)-1]] <= nums[i] {

    deque = deque[:len(deque)-1]
}
```

# 七、例题3：239. 滑动窗口最大值

## 题目

```text
nums = [1,3,-1,-3,5,3,6,7]

k = 3
```

输出：

```text
[3,3,5,5,6,7]
```

---

## 为什么存下标

单调队列通常：

```text
存下标
不存值
```

因为需要判断：

```text
元素是否已经滑出窗口
```

例如：

```text
nums:

0 1 2 3 4

1 3 -1 -3 5
```

队列：

```text
[1,4]
```

表示：

```text
nums[1]=3
nums[4]=5
```

---

## 标准代码

```go
func maxSlidingWindow(nums []int, k int) []int {

    deque := []int{}

    ans := []int{}

    for i := 0; i < len(nums); i++ {

        // 删除过期元素
        for len(deque) > 0 &&
            deque[0] <= i-k {

            deque = deque[1:]
        }

        // 删除较小元素
        for len(deque) > 0 &&
            nums[deque[len(deque)-1]] <= nums[i] {

            deque = deque[:len(deque)-1]
        }

        deque = append(deque, i)

        if i >= k-1 {
            ans = append(ans, nums[deque[0]])
        }
    }

    return ans
}
```

---

## 核心思想

队列中保存：

```text
未来有可能成为最大值的元素
```

而不是：

```text
窗口所有元素
```

---

## 为什么是O(n)

虽然有两层循环：

```go
for ...
    for ...
```

但：

```text
每个元素

最多入队一次
最多出队一次
```

因此：

```text
时间复杂度 O(n)

空间复杂度 O(k)
```
