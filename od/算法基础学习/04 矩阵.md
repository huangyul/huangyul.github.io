二维矩阵本质就是一个**带坐标的棋盘**。在算法中，无论是网格搜索、顺时针旋转还是螺旋遍历，核心都在于**把几何空间变换翻译成坐标索引（$i, j$）的变化**。

矩阵相关的题目，`80%` 都在考两类核心操作：

1. **边界收缩扫描**（如螺旋矩阵）
    
2. **空间对称映射与原地转换**（如旋转图像）
    

### 一、 螺旋遍历（边界收缩法）

#### 1. 核心概念大白话

想象你在吃一块方形夹心饼干，规则是：**只能沿着饼干外缘一圈一圈啃进去**。啃完最上面一排，最上面这层就没了；啃完最右边一列，最右边也削去一层。

_LeetCode 54. 螺旋矩阵_ 的硬性规则：

1. **方向固定**：严格按照 `左->右`、`上->下`、`右->左`、`下->上` 轮转。
    
2. **碰壁收缩**：每走完一条边，对应的边界线向内收缩 1 格；一旦**上界超过下界**或**左界超过右界**，立即停手。
    

#### 2. 直观反例与踩坑点

为什么很多人的代码在长方形矩阵中会重复打印或死循环？

- **正例（标准方阵 $3 \times 3$）**：
    
    边界按层对称收缩，最后一圈正好收缩到中心点 $(1, 1)$。
    
- **高频踩坑反例（扁长矩阵 $1 \times 4$：`[[1,2,3,4]]`）**：
    
    - 第一趟（左到右）：遍历了 `1, 2, 3, 4`，上边界下移，此时 `top > bottom`。
        
    - **错误逻辑**：如果不做越界校验，后续的“右到左”还会倒着再遍历一次 `3, 2, 1`，导致元素重复输出。
        

#### 3. 思路：四个边界

我们维护四个变量：

```
top    // 上边界
	bottom // 下边界
left   // 左边界
right  // 右边界
```

初始：

```
top = 0
bottom = m - 1
left = 0
right = n - 1
```

然后每一轮按照四个方向走：

```
→  从 left    到 right
↓  从 top     到 bottom
←  从 right   到 left
↑  从 bottom  到 top
```

走完一个方向，就把对应的边界向里面收缩。

#### 4. 代码拆解与实现

维护 4 个游标：`top`, `bottom`, `left`, `right`。比起复杂的转向状态机，维护 4 个物理边界直观且不会丢边界。



```Go
func spiralOrder(matrix [][]int) []int {
    if len(matrix) == 0 || len(matrix[0]) == 0 {
        return nil
    }
    m, n := len(matrix), len(matrix[0])
    top, bottom := 0, m-1
    left, right := 0, n-1
    res := make([]int, 0, m*n)

    for top <= bottom && left <= right {
        // 1. 从左向右走完顶部行
        for j := left; j <= right; j++ {
            res = append(res, matrix[top][j])
        }
        top++ // 啃掉了第一行，顶部边界下移

        // 2. 从上向下走完最右列
        for i := top; i <= bottom; i++ {
            res = append(res, matrix[i][right])
        }
        right-- // 啃掉了最右列，右边界左移

        // 关键防护 1：检查顶部是否已经穿过底部（防扁长矩阵重复扫描）
        if top <= bottom {
            for j := right; j >= left; j-- {
                res = append(res, matrix[bottom][j])
            }
            bottom-- // 底部边界上移
        }

        // 关键防护 2：检查左侧是否已经穿过右侧（防细长矩阵重复扫描）
        if left <= right {
            for i := bottom; i >= top; i-- {
                res = append(res, matrix[i][left])
            }
            left++ // 左侧边界右移
        }
    }
    return res
}
```

#### 5. 解题模板

```go
top, bottom := 0, m-1
left, right := 0, n-1

for top <= bottom && left <= right {

    // 左 -> 右
    ...

    top++

    // 上 -> 下
    ...

    right--

    // 右 -> 左
    if top <= bottom {
        ...
        bottom--
    }

    // 下 -> 上
    if left <= right {
        ...
        left++
    }
}
```


# 二维矩阵转置与旋转

## 一、核心概念

矩阵转换本质上就是：

> **元素坐标 `(i, j)` 发生变化。**

常见操作：

```text
转置：       (i, j) → (j, i)
顺时针90°：  (i, j) → (j, n-1-i)
逆时针90°：  (i, j) → (n-1-j, i)
```

实际写题时，旋转通常不直接套坐标公式，而是拆成：

```text
顺时针90° = 转置 + 左右翻转

逆时针90° = 转置 + 上下翻转
```

---

## 二、矩阵转置

例如：

```text
1 2 3
4 5 6
7 8 9

↓

1 4 7
2 5 8
3 6 9
```

核心：

```text
matrix[i][j] → matrix[j][i]
```

---

### LeetCode 867：Transpose Matrix

867 要求创建一个新的矩阵。

```go
func transpose(matrix [][]int) [][]int {
    m, n := len(matrix), len(matrix[0])

    // 原矩阵 m×n
    // 转置后变成 n×m
    res := make([][]int, n)
    for i := range res {
        res[i] = make([]int, m)
    }

    // (i,j) → (j,i)
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            res[j][i] = matrix[i][j]
        }
    }

    return res
}
```


## 三、原地转置

如果不创建 `res`，而是直接修改原矩阵：

```go
matrix[i][j], matrix[j][i] =
    matrix[j][i], matrix[i][j]
```

这时候属于**交换**。

所以：

> **原地交换时，每一对元素只能处理一次。**

因此只遍历主对角线的一侧：

```go
func transposeInPlace(matrix [][]int) {
    n := len(matrix)

    // 只处理主对角线右上方
    // 避免 (i,j) 和 (j,i) 被交换两次
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] =
                matrix[j][i], matrix[i][j]
        }
    }
}
```

这里：

```go
j := i + 1
```

有两个作用：

1. `j=i` 是主对角线，自己和自己交换，没有意义。
    
2. 只处理主对角线一侧，避免重复交换。

## 四、顺时针旋转 90°：LeetCode 48

例如：

```text
1 2 3
4 5 6
7 8 9
```

顺时针旋转：

```text
7 4 1
8 5 2
9 6 3
```

可以拆成两步：

```text
① 转置
② 每一行左右翻转
```

### 第一步

```text
1 2 3
4 5 6
7 8 9

↓

1 4 7
2 5 8
3 6 9
```

### 第二步

每一行左右翻转：

```text
1 4 7 → 7 4 1
2 5 8 → 8 5 2
3 6 9 → 9 6 3
```

---

## 完整 Go 实现

```go
func rotate(matrix [][]int) {
    n := len(matrix)

    // 第一步：转置
    // 只交换主对角线一侧，避免重复交换
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] =
                matrix[j][i], matrix[i][j]
        }
    }

    // 第二步：每一行左右翻转
    // 只交换一半，避免重复交换
    for i := 0; i < n; i++ {
        for j := 0; j < n/2; j++ {
            matrix[i][j], matrix[i][n-1-j] =
                matrix[i][n-1-j], matrix[i][j]
        }
    }
}
```

## 五、上下翻转

上下翻转：

```text
1 2 3
4 5 6
7 8 9

↓

7 8 9
4 5 6
1 2 3
```

这里交换的是：

```text
第0行 ↔ 第2行
第1行 ↔ 第1行（不需要）
```

Go 中：

```go
matrix[i]
```

代表**整行**，所以可以直接交换两行：

```go
func reverseRows(matrix [][]int) {
    n := len(matrix)

    // 只交换一半的行
    // matrix[i] 本身就是整行
    for i := 0; i < n/2; i++ {
        matrix[i], matrix[n-1-i] =
            matrix[n-1-i], matrix[i]
    }
}
```

所以它只需要一层循环。

## 六、逆时针旋转 90°

可以理解为：

```text
逆时针90° = 转置 + 上下翻转
```

完整代码：

```go
func rotateLeft(matrix [][]int) {
    n := len(matrix)

    // 第一步：转置
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] =
                matrix[j][i], matrix[i][j]
        }
    }

    // 第二步：上下翻转
    // matrix[i] 是整行，所以直接交换整行
    for i := 0; i < n/2; i++ {
        matrix[i], matrix[n-1-i] =
            matrix[n-1-i], matrix[i]
    }
}
```

## 七、最终记忆

### 转置

```text
(i,j) → (j,i)
```

原地：

```go
for i := 0; i < n; i++ {
    for j := i + 1; j < n; j++ {
        swap(matrix[i][j], matrix[j][i])
    }
}
```

### 顺时针 90°

```text
转置 + 左右翻转
```

### 逆时针 90°

```text
转置 + 上下翻转
```

### 交换类操作

```text
转置：      j = i + 1
左右翻转：  j < n/2
上下翻转：  i < n/2
```

最核心的一句话：

> **新矩阵可以直接遍历；原地交换要避免重复交换。**
