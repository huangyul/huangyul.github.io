二维矩阵本质就是一个**带坐标的棋盘**。在算法中，无论是网格搜索、顺时针旋转还是螺旋遍历，核心都在于**把几何空间变换翻译成坐标索引（$i, j$）的变化**。

矩阵相关的题目，`80%` 都在考两类核心操作：

1. **边界收缩扫描**（如螺旋矩阵）
    
2. **空间对称映射与原地转换**（如旋转图像）
    

### 一、 螺旋遍历（边界收缩法）

#### 1. 核心概念大白话

想象你在吃一块方形夹心饼干，规则是：**只能沿着饼干外缘一圈一圈啃进去**。啃完最上面一排，最上面这层就没了；啃完最右边一列，最右边也削去一层。

_LeetCode 54. 螺旋矩阵_ 的硬性规则：

1. **方向固定**：严格按照 `左->右`、`上->下`、`右->左`、`下->上` 轮转。
    
2. **碰壁收缩**：每走完一条边，对应的边界线向内收缩 1 格；一旦**上界超过下界**或**左界超过右界**，立即停手。
    

#### 2. 直观反例与踩坑点

为什么很多人的代码在长方形矩阵中会重复打印或死循环？

- **正例（标准方阵 $3 \times 3$）**：
    
    边界按层对称收缩，最后一圈正好收缩到中心点 $(1, 1)$。
    
- **高频踩坑反例（扁长矩阵 $1 \times 4$：`[[1,2,3,4]]`）**：
    
    - 第一趟（左到右）：遍历了 `1, 2, 3, 4`，上边界下移，此时 `top > bottom`。
        
    - **错误逻辑**：如果不做越界校验，后续的“右到左”还会倒着再遍历一次 `3, 2, 1`，导致元素重复输出。
        

#### 3. 思路：四个边界

我们维护四个变量：

```
top    // 上边界
	bottom // 下边界
left   // 左边界
right  // 右边界
```

初始：

```
top = 0
bottom = m - 1
left = 0
right = n - 1
```

然后每一轮按照四个方向走：

```
→  从 left    到 right
↓  从 top     到 bottom
←  从 right   到 left
↑  从 bottom  到 top
```

走完一个方向，就把对应的边界向里面收缩。

#### 4. 代码拆解与实现

维护 4 个游标：`top`, `bottom`, `left`, `right`。比起复杂的转向状态机，维护 4 个物理边界直观且不会丢边界。



```Go
func spiralOrder(matrix [][]int) []int {
    if len(matrix) == 0 || len(matrix[0]) == 0 {
        return nil
    }
    m, n := len(matrix), len(matrix[0])
    top, bottom := 0, m-1
    left, right := 0, n-1
    res := make([]int, 0, m*n)

    for top <= bottom && left <= right {
        // 1. 从左向右走完顶部行
        for j := left; j <= right; j++ {
            res = append(res, matrix[top][j])
        }
        top++ // 啃掉了第一行，顶部边界下移

        // 2. 从上向下走完最右列
        for i := top; i <= bottom; i++ {
            res = append(res, matrix[i][right])
        }
        right-- // 啃掉了最右列，右边界左移

        // 关键防护 1：检查顶部是否已经穿过底部（防扁长矩阵重复扫描）
        if top <= bottom {
            for j := right; j >= left; j-- {
                res = append(res, matrix[bottom][j])
            }
            bottom-- // 底部边界上移
        }

        // 关键防护 2：检查左侧是否已经穿过右侧（防细长矩阵重复扫描）
        if left <= right {
            for i := bottom; i >= top; i-- {
                res = append(res, matrix[i][left])
            }
            left++ // 左侧边界右移
        }
    }
    return res
}
```
