
**哈希表（Hash Table）通过哈希函数将键（Key）映射到数组下标，从而在平均 **$O(1)$** 的时间复杂度内完成插入、删除和查找。在算法题中，它最常见的三种形态是：**快速映射**、**元素去重** 与 **频次统计**。

# 1. 快速映射 (Key-Value Lookup)

用空间换时间，把内层循环的线性搜索 $O(n)$ 降为 $O(1)$ 的直接映射查找。

**典型例题：LeetCode 1. 两数之和 (Two Sum)**

- **思路**：遍历数组时，对于当前元素 `num`，我们需要寻找的目标差值是 `target - num`。通过哈希表记录已经遍历过的数字及其下标：如果差值存在于表中，直接返回两个下标；不存在则存入当前数值。
    
- **复杂度**：时间 $O(n)$，空间 $O(n)$。
    



```Go
func twoSum(nums []int, target int) []int {
    // 映射关系：num -> index
    seen := make(map[int]int, len(nums))
    for i, num := range nums {
        complement := target - num
        if idx, ok := seen[complement]; ok {
            return []int{idx, i}
        }
        seen[num] = i
    }
    return nil
}
```

# 2. 元素去重 (Set / Existence Check)

Go 语言没有内置的 `Set` 类型，通常使用 `map[T]struct{}` 替代。`struct{}` 不占用内存（`unsafe.Sizeof(struct{}{}) == 0`），是 Go 中实现纯集合与去重的标准实践。

**典型例题：LeetCode 217. 存在重复元素 (Contains Duplicate)**

- **思路**：维护一个集合，遍历数组，一旦发现当前数字已在集合中，说明存在重复，立即返回 `true`；遍历结束仍无冲突则返回 `false`。
    
- **复杂度**：时间 $O(n)$，空间 $O(n)$。
    



```Go
func containsDuplicate(nums []int) bool {
    // 使用空结构体实现 HashSet，零内存开销
    set := make(map[int]struct{}, len(nums))
    for _, num := range nums {
        if _, exists := set[num]; exists {
            return true
        }
        set[num] = struct{}{}
    }
    return false
}
```

# 3. 频次统计 (Frequency Counter)

用于计算字符、数字或状态的出现次数。由于 Go 的 `map[key]int` 在访问不存在的 key 时会自动返回该类型的零值 `0`，自增计数代码非常简洁。

**典型例题：LeetCode 242. 有效的字母异位词 (Valid Anagram)**

- **思路**：判断两个字符串是否由完全相同的字符及相同频次构成。先遍历第一个字符串累加频次，再遍历第二个字符串扣减频次。出现负数或长度不等即为无效。
    
- **说明**：小写字母固定 26 个时，工程和刷题中亦可用长度 26 的数组作为高效的定长哈希表；但通用的字符集/哈希表模式如下：
    
- **复杂度**：时间 $O(n)$，空间 $O(k)$（$k$ 为不同字符数）。
    



```Go
func isAnagram(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }

    counts := make(map[rune]int)
    for _, ch := range s {
        counts[ch]++
    }

    for _, ch := range t {
        counts[ch]--
        if counts[ch] < 0 {
            return false
        }
    }
    return true
}
```

**使用数组代替的写法**

题目限定字符集为小写字母 `a-z`，天然具有连续紧凑的 ASCII 码范围（97 到 122）。通过 `c - 'a'` 可以将字符直接映射到 `[0, 25]` 的连续内存下标

```go
func isAnagram(s string, t string) bool {
  if len(s) != len(t) {
    return false
  }

  var counts [26]int
  for i := 0; i < len(s); i++ {
    counts[s[i]-'a']++
    counts[t[i]-'a']--
  }
  
  for _, n := range counts {
    if n != 0 {
      return false
    }
  }

  return true
}
```


# 4. 特征哈希

寻找一个能唯一标识一组异位词的“指纹（Key）”，用 `map[Key][]string` 实现归类

**典型例题：LeetCode 49. 字母异位词分组**

面对异位词归类，核心痛点是：**如何让 `eat`、`tea`、`ate` 在哈希表中落到同一个桶里？**

常见的特征设计有两种：

1. **方案一：字符排序法（最直观、面试首选）**
    
    - **核心直觉**：将每个字符串拆成 byte 切片进行字典序排序。因为异位词包含的字符完全相同，排序后的字符串一定唯一对应（如 `eat`、`tea`、`ate` 排序后均为 `aet`）。
        
    - **指纹**：`sortedStr := string(bytes)`。
        
    - **时间复杂度**：设字符串总数 $N$，单个字符串最大长度 $K$。每个词排序需 $O(K \log K)$，总复杂度为 $O(N \cdot K \log K)$。在 $K \le 100$ 的约束下效率极高。
        
2. **方案二：字符计数数组做 Key（Go 语言精妙解法，进阶提速）**
    
    - **核心直觉**：题目限定字符仅为小写英文字母（26个），可以用长度为 26 的固定数组 `[26]byte` 记录字符出现频次。
        
    - **Go 语言特性**：在 Go 中，**定长数组是值类型（Value Type），支持直接作为 `map` 的 Key 进行相等性比较**（而切片 `[]int` 不能做 Key）。
        
    - **时间复杂度**：仅需一趟遍历统计字符频率，单词耗时 $O(K)$，总复杂度降至严格线性 $O(N \cdot K)$。
        

#### 方式一：字符计数做 Key（推荐：理论复杂度最优，体现 Go 语言机制）


```Go
package main

// GroupAnagrams 字母异位词分组 - 计数哈希法
func groupAnagrams(strs []string) [][]string {
	// 1. 初始化哈希表：Key 为 26 位定长数组（值类型可直接哈希），Value 为同组字符串切片
	mp := make(map[[26]byte][]string)

	// 2. 遍历每个字符串，提取特征指纹
	for _, s := range strs {
		var cnt [26]byte
		for i := 0; i < len(s); i++ {
			cnt[s[i]-'a']++
		}
		// 3. 将原字符串挂载到对应特征的桶中
		mp[cnt] = append(mp[cnt], s)
	}

	// 4. 收集聚类结果
	ans := make([][]string, 0, len(mp))
	for _, group := range mp {
		ans = append(ans, group)
	}

	return ans
}
```

#### 方式二：排序作为 Key（经典排序哈希法）


```Go
import "sort"

func groupAnagramsSort(strs []string) [][]string {
	mp := make(map[string][]string)

	for _, s := range strs {
		b := []byte(s)
		sort.Slice(b, func(i, j int) bool {
			return b[i] < b[j]
		})
		sortedKey := string(b)
		mp[sortedKey] = append(mp[sortedKey], s)
	}

	ans := make([][]string, 0, len(mp))
	for _, group := range mp {
		ans = append(ans, group)
	}
	return ans
}
```

# 5. 哈希集合查找前驱 `num - 1`

**LeetCode 128. 最长连续序列**


1. **集合去重**：遍历数组，用 Go 的 `map[int]struct{}` 构建哈希集合（去重同时支持 $O(1)$ 查找）。
    
2. **枚举潜在起点**：遍历哈希集合中的每个数 `num`。
    
3. **嗅探起点**：检查 `num - 1` 是否在哈希表中。若在，跳过；若不在，以 `num` 作为起点开始计数。
    
4. **向右延伸**：循环探测 `curNum + 1`，累加当前序列长度 `curLen`。
    
5. **更新全局最大值**：`maxLen = max(maxLen, curLen)`，遍历结束后返回 `maxLen`。


```Go
package main

func longestConsecutive(nums []int) int {
	if len(nums) == 0 {
		return 0
	}

	// 1. 构建哈希集合，使用 struct{} 零内存开销实现 Set
	numSet := make(map[int]struct{}, len(nums))
	for _, x := range nums {
		numSet[x] = struct{}{}
	}

	maxLen := 0

	// 2. 遍历集合中的每个元素
	for num := range numSet {
		// 3. 核心剪枝：如果 num-1 存在，说明 num 绝不是链头，跳过
		if _, exists := numSet[num-1]; exists {
			continue
		}

		// 4. 当前 num 是连续区间的起点，向右延展统计长度
		curNum := num
		curLen := 1

		for {
			if _, exists := numSet[curNum+1]; exists {
				curNum++
				curLen++
			} else {
				break
			}
		}

		// 5. 更新最大连续长度
		if curLen > maxLen {
			maxLen = curLen
		}
	}

	return maxLen
}
```

# 6. 前缀和 + 哈希表

**LeetCode 560. 和为 K 的子数组 (Subarray Sum Equals K)**

**两数之和思想转换**： 遍历数组计算当前的前缀和 $S$。如果以当前位置为子数组的终点，我们要找的是：**在当前位置之前，出现过多少次前缀和为 $S - k$ 的位置**？ 用哈希表 `countMap[sum]` 实时记录前缀和出现的**频次**，边走边查、边走边存，单趟遍历（$O(N)$）即可完成统计。

```go
package main

// subarraySum 统计和为 k 的连续子数组个数
func subarraySum(nums []int, k int) int {
	// 1. 初始化哈希表：key 为前缀和，value 为该前缀和出现的频次
	prefixFreq := make(map[int]int)

	// 2. 哨兵初始化：前缀和为 0 默认出现过 1 次
	// 作用：当某个前缀和恰好 sum == k 时，sum - k == 0，能正确计入从下标 0 开始的子数组
	prefixFreq[0] = 1

	currentSum := 0
	ans := 0

	// 3. 一趟扫描（One-pass）
	for _, num := range nums {
		currentSum += num

		// 检查此前是否存在前缀和为 (currentSum - k)
		// 如果存在，说明从那个前缀和结束的位置到当前位置构成的子数组之和就是 k
		if count, exists := prefixFreq[currentSum-k]; exists {
			ans += count
		}

		// 将当前前缀和的频次加 1，记录进哈希表
		prefixFreq[currentSum]++
	}

	return ans
}
```

## LeetCode 525. 连续数组（Contiguous Array）

1. **正负抵消**：遇到 `1` 记为 `+1`，遇到 `0` 记为 `-1`。当一段区间内 `1` 和 `0` 的数量完全相同时，该区间各元素之和必然为 `0`。
    
2. **前缀和的物理落点**：
    
    记下标 $0 \dots i$ 的前缀和为 $prefixSum[i]$。
    
    如果子数组 $(j, i]$（即从下标 $j+1$ 到 $i$）的元素和为 0，则有：
    
    $$prefixSum[i] - prefixSum[j] = 0 \implies prefixSum[i] == prefixSum[j]$$
    
    **结论**：只要在遍历过程中发现当前的前缀和以前出现过，说明两段前缀之间的子数组内 0 和 1 的数量刚好平衡！
    
3. **贪心取最长**：
    
    我们需要求的是**最长**长度 $i - j$。为了让长度最大，减数 $j$ 必须尽可能小。因此哈希表中**只记录每个前缀和第一次出现的最早下标**，后续再遇到相同的前缀和时，绝不覆盖更新！
    
4. **哨兵边界**：
    
    在开始遍历前，初始前缀和为 `0`，虚拟下标为 `-1`，即 `map[0] = -1`。这样如果从数组开头到当前下标 $i$ 的和正好是 0，计算长度即为 $i - (-1) = i + 1$，直接消除开头特判。
    

- **数据规模**：$N \le 10^5$。暴力两重循环 $O(N^2)$ 必定超时；哈希表前缀和单次扫描时间复杂度 $O(N)$，空间复杂度 $O(N)$，稳过。
    

#### 核心函数模式（LeetCode 标准）

```Go
package main

func findMaxLength(nums []int) int {
	// 1. 初始化哈希表：key 为前缀和，value 为该前缀和首次出现的下标
	// 边界哨兵：前缀和为 0 首次出现在下标 -1
	prefixMap := map[int]int{0: -1}

	maxLen := 0
	prefixSum := 0

	for i, num := range nums {
		// 2. 将 0 映射为 -1，1 保持为 1
		if num == 1 {
			prefixSum += 1
		} else {
			prefixSum -= 1
		}

		// 3. 检查当前前缀和是否出现过
		if firstIndex, ok := prefixMap[prefixSum]; ok {
			// 出现过：计算区间长度 (firstIndex, i]，并尝试更新全局最大值
			curLen := i - firstIndex
			if curLen > maxLen {
				maxLen = curLen
			}
		} else {
			// 未出现过：只在第一次出现时记录下标（贪心保证下标最早）
			prefixMap[prefixSum] = i
		}
	}

	return maxLen
}
```

# Go 语言中哈希表的核心注意事项

| **维度**       | **特性与底层原理**                                         | **刷题/工程实践建议**                                             |
| ------------ | --------------------------------------------------- | --------------------------------------------------------- |
| **容量预分配**    | 触发扩容（Load Factor 超过约 6.5）会导致翻倍重建 `hmap` 与渐进式搬迁。     | 预知数据量时显式传参：`make(map[K]V, hint)`，减少扩容开销。                  |
| **Key 的合法性** | 只有**可比较类型（Comparable）**才能作为 Key。                    | 切片（`slice`）、映射（`map`）、函数不能作 Key。字符串、数字、定长数组或可比结构体可作为 Key。 |
| **遍历无序性**    | Go 运行时在迭代 map 时引入了随机偏移量。                            | 永远不要依赖 map 遍历的顺序；若需保序，须额外维护一个记录 Key 插入顺序的切片。              |
| **零值可用性**    | 未初始化的 `var m map[string]int` 读取返回零值，但写入会触发 `panic`。 |                                                           |
