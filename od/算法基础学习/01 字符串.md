
# 1. 字符遍历：Byte vs Rune

Go 中通过下标访问字符串返回的是原始字节（`byte` 即 `uint8`），处理包含非 ASCII 字符（如中文、Emoji）时直接按字节切片会导致乱码。

- **按字节遍历**：适合纯 ASCII 字符串（如 URL、数字串、协议控制符）。
    
- **按 Unicode 标量遍历（`rune` 即 `int32`）**：使用 `range` 循环，Go 会自动解码 UTF-8。
    



```Go
package main

import "fmt"

func traverseDemo() {
	s := "Go语言"

	// 1. 字节遍历（Len 统计的是字节数：2 + 3*2 = 8 字节）
	fmt.Printf("Byte len: %d\n", len(s)) // 输出: 8
	for i := 0; i < len(s); i++ {
		fmt.Printf("%x ", s[i]) // 打印原始 16 进制字节
	}
	fmt.Println()

	// 2. Rune 遍历（range 自动解码多字节字符）
	for idx, r := range s {
		fmt.Printf("index: %d, char: %c\n", idx, r)
	}
}
```

# 2. 字符串分割与高效拼接

使用 `strings.Split` 分割时需注意边界：若输入为空，`strings.Split("", ",")` 返回 `[""]`（长度为 1 的切片，而非空切片）。

在频繁拼接字符串时，避免使用 `+` 产生 $O(N^2)$ 的内存重新分配，优先使用 `strings.Builder`。



```Go
package main

import (
	"strings"
)

// CleanAndJoin 分割标签、去除首尾空格并重组
func CleanAndJoin(rawTags string) string {
	parts := strings.Split(rawTags, ",")
	var builder strings.Builder

	for _, p := range parts {
		trimmed := strings.TrimSpace(p)
		if len(trimmed) == 0 {
			continue
		}
		if builder.Len() > 0 {
			builder.WriteString("; ")
		}
		builder.WriteString(trimmed)
	}
	return builder.String()
}
```

# 3. 正则表达式提取

Go 标准库 `regexp` 实现了 RE2 引擎，保证线性时间复杂度（不使用回溯算法，避免正则拒绝服务攻击 ReDoS）。

- **性能注意**：高频场景必须先使用 `regexp.MustCompile` 预编译正则对象，避免在循环内部重复编译。
    



```Go
package main

import (
	"fmt"
	"regexp"
)

// 预编译正则（捕获键值对，例如 key=val）
var kvRegex = regexp.MustCompile(`([a-zA-Z0-9_]+)=([a-zA-Z0-9_-]+)`)

func extractKeyValues(logLine string) map[string]string {
	result := make(map[string]string)
	matches := kvRegex.FindAllStringSubmatch(logLine, -1)
	
	for _, match := range matches {
		// match[0]: 完整匹配, match[1]: 捕获组1, match[2]: 捕获组2
		result[match[1]] = match[2]
	}
	return result
}
```

# 4. HashMap 频次映射与滑动窗口

哈希表是解决“字母异位词”、“无重复字符的最长子串”等经典算法题的核心数据结构。纯 ASCII 字符可直接用固定长度数组（`[128]int` 或 `[256]int`）替代 `map` 获得更低的内存开销与更优的缓存局部性。

**经典案例：无重复字符的最长子串（滑动窗口）**



```Go
package main

func lengthOfLongestSubstring(s string) int {
	lastIndex := make(map[rune]int)
	maxLen, start := 0, 0

	for end, char := range s {
		// 如果字符在当前窗口内重复，收缩左边界
		if prevIdx, found := lastIndex[char]; found && prevIdx >= start {
			start = prevIdx + 1
		}
		lastIndex[char] = end

		curLen := end - start + 1
		if curLen > maxLen {
			maxLen = curLen
		}
	}
	return maxLen
}
```

# 5. 协议解析（Protocol Parsing）

在网络通信和存储中，文本协议通常有两类设计：

1. **行驱动分隔协议**（如 HTTP/1.1 首部、Redis RESP）：以 `\r\n` 分隔。
    
2. **定长/变长包头协议**（TLV：Tag-Length-Value）：防止粘包与半包。
    

以下为基于状态机/双指针实现的轻量级 Key-Value 查询串解析器（如解析 `foo=1&bar=hello%20world&flag`）：



```Go
package main

import (
	"fmt"
	"strings"
)

// ParseQueryString 手工状态解析，相比正则速度更快、无额外内存分配
func ParseQueryString(query string) map[string]string {
	params := make(map[string]string)
	n := len(query)
	start := 0

	for i := 0; i <= n; i++ {
		// 遇到分隔符或到达末尾
		if i == n || query[i] == '&' {
			if i > start {
				pair := query[start:i]
				eqIdx := strings.IndexByte(pair, '=')
				if eqIdx != -1 {
					key := pair[:eqIdx]
					val := pair[eqIdx+1:]
					params[key] = val
				} else {
					params[pair] = "" // 只有 key 没有 value
				}
			}
			start = i + 1
		}
	}
	return params
}

func main() {
	query := "id=1001&status=active&debug=&mode=test"
	res := ParseQueryString(query)
	for k, v := range res {
		fmt.Printf("%s: %s\n", k, v)
	}
}
```

# 字符串操作的核心选型对比

|**操作场景**|**推荐方式**|**避免做法**|**核心原因**|
|---|---|---|---|
|**字符统计**|`[256]int` / `[128]int`|`map[rune]int`（纯 ASCII 场景）|数组零堆分配，缓存连续访问极快|
|**多串拼接**|`strings.Builder`|`s += other` 循环累加|减少扩容产生的频繁内存分配与拷贝|
|**规则匹配**|双指针 / `strings.IndexByte`|随处临时 `regexp.Compile`|RE2 编译成本高；简单查找指针遍历更快|
|**多语言文本**|`[]rune` / `utf8.RuneCountInString`|直接按字节切片 `s[:k]`|破坏 UTF-8 变长字节编码边界导致乱码|
