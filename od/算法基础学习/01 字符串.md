
# 1. 字符遍历：Byte vs Rune

Go 中通过下标访问字符串返回的是原始字节（`byte` 即 `uint8`），处理包含非 ASCII 字符（如中文、Emoji）时直接按字节切片会导致乱码。

- **按字节遍历**：适合纯 ASCII 字符串（如 URL、数字串、协议控制符）。
    
- **按 Unicode 标量遍历（`rune` 即 `int32`）**：使用 `range` 循环，Go 会自动解码 UTF-8。
    



```Go
package main

import "fmt"

func traverseDemo() {
	s := "Go语言"

	// 1. 字节遍历（Len 统计的是字节数：2 + 3*2 = 8 字节）
	fmt.Printf("Byte len: %d\n", len(s)) // 输出: 8
	for i := 0; i < len(s); i++ {
		fmt.Printf("%x ", s[i]) // 打印原始 16 进制字节
	}
	fmt.Println()

	// 2. Rune 遍历（range 自动解码多字节字符）
	for idx, r := range s {
		fmt.Printf("index: %d, char: %c\n", idx, r)
	}
}
```

# 2. 字符串分割与高效拼接

使用 `strings.Split` 分割时需注意边界：若输入为空，`strings.Split("", ",")` 返回 `[""]`（长度为 1 的切片，而非空切片）。

在频繁拼接字符串时，避免使用 `+` 产生 $O(N^2)$ 的内存重新分配，优先使用 `strings.Builder`。



```Go
package main

import (
	"strings"
)

// CleanAndJoin 分割标签、去除首尾空格并重组
func CleanAndJoin(rawTags string) string {
	parts := strings.Split(rawTags, ",")
	var builder strings.Builder

	for _, p := range parts {
		trimmed := strings.TrimSpace(p)
		if len(trimmed) == 0 {
			continue
		}
		if builder.Len() > 0 {
			builder.WriteString("; ")
		}
		builder.WriteString(trimmed)
	}
	return builder.String()
}
```

# 3. 正则表达式提取

Go 标准库 `regexp` 实现了 RE2 引擎，保证线性时间复杂度（不使用回溯算法，避免正则拒绝服务攻击 ReDoS）。

- **性能注意**：高频场景必须先使用 `regexp.MustCompile` 预编译正则对象，避免在循环内部重复编译。
    



```Go
package main

import (
	"fmt"
	"regexp"
)

// 预编译正则（捕获键值对，例如 key=val）
var kvRegex = regexp.MustCompile(`([a-zA-Z0-9_]+)=([a-zA-Z0-9_-]+)`)

func extractKeyValues(logLine string) map[string]string {
	result := make(map[string]string)
	matches := kvRegex.FindAllStringSubmatch(logLine, -1)
	
	for _, match := range matches {
		// match[0]: 完整匹配, match[1]: 捕获组1, match[2]: 捕获组2
		result[match[1]] = match[2]
	}
	return result
}
```

# 4. HashMap 频次映射与滑动窗口

哈希表是解决“字母异位词”、“无重复字符的最长子串”等经典算法题的核心数据结构。纯 ASCII 字符可直接用固定长度数组（`[128]int` 或 `[256]int`）替代 `map` 获得更低的内存开销与更优的缓存局部性。

### 典型模式与 Go 代码实战

#### 1. 字符频次统计：字母异位词判定

**问题：** 给定两字符串 $s$ 和 $t$，判断 $t$ 是否为 $s$ 的字母异位词（字符种类与频次完全相同）。

**思路：** 用长度 26 的数组作为哈希计数器，遍历 $s$ 自增，遍历 $t$ 自减。最终所有项必须归零。



```Go
func isAnagram(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }
    
    var count [26]int
    for i := 0; i < len(s); i++ {
        count[s[i]-'a']++
        count[t[i]-'a']--
    }
    
    for _, c := range count {
        if c != 0 {
            return false
        }
    }
    return true
}
```

#### 2. 位置映射 + 滑动窗口：无重复字符的最长子串

**问题：** 求字符串中不含重复字符的最长子串长度。

**思路：** 用哈希表记录**字符最后一次出现的索引**。遍历右边界 `right` 时，如果遇到重复字符且该字符上次出现位置处于当前窗口内，直接将左边界 `left` 跳跃到 `lastIndex + 1`。使用一个map去记录字符出现的位置，如果发现有重复出现，则把left设置成原本位置的下一个（往后移动一位），这样保证不会丢失之前的



```Go
func lengthOfLongestSubstring(s string) int {
    // 记录字符最后出现的下标位置，初始化为 -1
    lastIndex := make(map[byte]int)
    maxLen := 0
    left := 0

    for right := 0; right < len(s); right++ {
        ch := s[right]
        if prev, exists := lastIndex[ch]; exists && prev >= left {
            // 发生重复，左指针直接跃过前一次出现的字符
            left = prev + 1
        }
        lastIndex[ch] = right
        
        curLen := right - left + 1
        if curLen > maxLen {
            maxLen = curLen
        }
    }
    return maxLen
}
```

#### 3. 数组作为 Key：字母异位词分组

**问题：** 给你一个字符串数组，请你将字母异位词组合在一起。

**思路：** 每个单词统计其 26 个字母的频次，将该频次数组作为 Map 的键。Go 中固定大小的数组（如 `[26]int`）具有值语义，**可直接作为 map 的 key**。



```Go
func groupAnagrams(strs []string) [][]string {
    groups := make(map[[26]int][]string)

    for _, str := range strs {
        var count [26]int
        for i := 0; i < len(str); i++ {
            count[str[i]-'a']++
        }
        // [26]int 可直接作为 map key
        groups[count] = append(groups[count], str)
    }

    result := make([][]string, 0, len(groups))
    for _, group := range groups {
        result = append(result, group)
    }
    return result
}
```

#### 4. 双向映射：字符串同构判定

**问题：** 给定两字符串 $s$ 和 $t$，判断它们是否同构（$s$ 中每个字符可唯一映射为 $t$ 中字符，且反向亦成立）。

**思路：** 单向映射容易出现多对一（例如 `ab -> aa`），因此需要维护双向映射，或分别记录两者的映射关系。



```Go
func isIsomorphic(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }

    s2t := make(map[byte]byte)
    t2s := make(map[byte]byte)

	for i := 0; i < len(s); i++ {
		sc, tc := s[i], t[i] // sc 是 s 的当前字符，tc 是 t 的当前字符
		
		// 检查规矩 1：sc 之前有没有认准过别人？
		// 比如 sc 是 'o'，如果之前记录了 'o' -> 'a'，但这次 tc 竟然是 'r'，那就穿帮了
		if mapped, ok := s2t[sc]; ok && mapped != tc {
			return false
		}
	
		// 检查规矩 2：tc 之前有没有被别人霸占过？
		// 比如 tc 是 'b'，如果之前记录了 'b' 来自于 'b'，这次 sc 竟然是 'd'，那就撞车了
		if mapped, ok := t2s[tc]; ok && mapped != sc {
			return false
		}
		
		// 没冲突，那就正式写入字典，绑定两者的关系
		s2t[sc] = tc
		t2s[tc] = sc
	}
    return true
}
```

# 5. 协议解析（Protocol Parsing）

在网络通信和存储中，文本协议通常有两类设计：

1. **行驱动分隔协议**（如 HTTP/1.1 首部、Redis RESP）：以 `\r\n` 分隔。
    
2. **定长/变长包头协议**（TLV：Tag-Length-Value）：防止粘包与半包。
    

以下为基于状态机/双指针实现的轻量级 Key-Value 查询串解析器（如解析 `foo=1&bar=hello%20world&flag`）：



```Go
package main

import (
	"fmt"
	"strings"
)

// ParseQueryString 手工状态解析，相比正则速度更快、无额外内存分配
func ParseQueryString(query string) map[string]string {
	params := make(map[string]string)
	n := len(query)
	start := 0

	for i := 0; i <= n; i++ {
		// 遇到分隔符或到达末尾
		if i == n || query[i] == '&' {
			if i > start {
				pair := query[start:i]
				eqIdx := strings.IndexByte(pair, '=')
				if eqIdx != -1 {
					key := pair[:eqIdx]
					val := pair[eqIdx+1:]
					params[key] = val
				} else {
					params[pair] = "" // 只有 key 没有 value
				}
			}
			start = i + 1
		}
	}
	return params
}

func main() {
	query := "id=1001&status=active&debug=&mode=test"
	res := ParseQueryString(query)
	for k, v := range res {
		fmt.Printf("%s: %s\n", k, v)
	}
}
```

# 字符串操作的核心选型对比

|**操作场景**|**推荐方式**|**避免做法**|**核心原因**|
|---|---|---|---|
|**字符统计**|`[256]int` / `[128]int`|`map[rune]int`（纯 ASCII 场景）|数组零堆分配，缓存连续访问极快|
|**多串拼接**|`strings.Builder`|`s += other` 循环累加|减少扩容产生的频繁内存分配与拷贝|
|**规则匹配**|双指针 / `strings.IndexByte`|随处临时 `regexp.Compile`|RE2 编译成本高；简单查找指针遍历更快|
|**多语言文本**|`[]rune` / `utf8.RuneCountInString`|直接按字节切片 `s[:k]`|破坏 UTF-8 变长字节编码边界导致乱码|
