# 冒泡排序

冒泡排序只会操作相邻的两个数据。每次冒泡操作都会对相邻的两个元素进行比较，看是否满足大小关系要求。如果不满足就让它俩互换。一次冒泡会让至少一个元素移动到它应该在的位置，重复n次，就完成了n个数据的排序工作。

```go
func bubbleSort(arr []int) []int {
  n := len(arr)
  for i := 0; i < n; i++ {
    flag := true
    for j := 0; j < n-1-i; j++ {
      if arr[j] > arr[j+1] {
        arr[j], arr[j+1] = arr[j+1], arr[j]
        flag = false
      }
    }
    if flag {
      break
    }
  }
  return arr
}
```

# 插入排序

**插入排序（Insertion Sort）** 的工作机制类似于摸牌起牌：每次拿到一张新牌，从右向左扫描已排好序的手牌，找到合适的位置插入进去。

### 核心原理

1. **区间划分**：将数组分为两部分——左侧为**有序区间**（初始仅包含第 1 个元素），右侧为**无序区间**。
    
2. **逐步插入**：遍历无序区间，每次取出一个元素（称为 `key` 或当前待插入值）。
    
3. **后移腾位**：将 `key` 与有序区间的元素从右往左依次比较，若有序区元素大于 `key`，则将其向右移动一位。
    
4. **定位放入**：找到首个不大于 `key` 的位置，将 `key` 插入到该空位后方。

```go
func insertionSort(arr []int) {
  n := len(arr)
  if n <= 1 {
    return
  }

  for i := 1; i < n; i++ {
    cur := arr[i]
    j := i - 1
    for j >= 0 && arr[j] > cur {
      arr[j+1] = arr[j]
      j--
    }
    arr[j+1] = cur
  }
}
```

# 选择排序

核心思想是：每一轮从未排序的序列中**选出最小（或最大）的一个元素**，存放到已排序序列的末尾，直到全部待排序的数据元素排完。

### 核心原理与执行流程

1. **初始状态**：有序区为空，无序区为 `[0, n-1]`。
    
2. **寻找极值**：在当前的无序区中遍历扫描，记录最小元素的索引 `minIndex`。
    
3. **位置交换**：将找到的最小元素与无序区的首个元素交换位置。
    
4. **推进边界**：有序区扩展 1 位，无序区缩减 1 位；重复上述过程 $n-1$ 轮完成排序。

```go
func selectionSort(arr []int) {
  n := len(arr)
  if n <= 1 {
    return
  }

  for i := 0; i < n-1; i++ {
    idx := i
    for j := i + 1; j < n; j++ {
      if arr[j] < arr[idx] {
        idx = j
      }
    }
    if idx != i {
      arr[i], arr[idx] = arr[idx], arr[i]
    }
  }
}
```


# 归并排序（Merge Sort）

基于**分治思想**：

1. **分 (Divide)**：把待排序数组从中间切分成左右两部分，递归拆分，直到子数组长度为 1（单个元素天然有序）。
2. **治 (Conquer)**：将两个已经有序的子数组合并成一个大的有序数组。
3. **合并 (Merge)**：双指针依次对比左右数组头部元素，取较小值放入结果，剩余部分直接追加。

> 复杂度
> 
> - 时间：\(O(n\log n)\)，最好 / 最坏 / 平均都是 \(n\log n\)
> - 空间：\(O(n)\)，需要辅助数组做合并
> - 稳定性：**稳定排序**，相等元素相对顺序不变

### 核心流程示例

数组 `[38,27,43,3,9,82,10]`

1. 不断对半拆分 → `[38,27,43]`、`[3,9,82,10]` … 直到单元素
2. 两两合并有序：`[27,38]`、`[3,43]` …
3. 逐层向上合并得到完整有序数组。

```go
// mergeSort 对输入切片进行归并排序
func mergeSort(arr []int) []int {
  n := len(arr)
  // 边界处理：空切片或单个元素无需排序
  if n <= 1 {
    return arr
  }

  // 提前开辟全局辅助空间 temp，避免递归过程中重复分配内存
  temp := make([]int, n)
  mergeHelper(arr, 0, n-1, temp)
  return arr
}

  

// mergeHelper 递归切分并合并 [left, right] 区间
func mergeHelper(arr []int, left, right int, temp []int) {
  // 1. 递归终止条件：区间长度为 1 或无效区间
  if left >= right {
    return
  }

  // 计算中点，防止 (left + right) 导致整数溢出
  mid := left + (right-left)/2

  // 2. 分治：递归对左右两半分别进行排序
  mergeHelper(arr, left, mid, temp)
  mergeHelper(arr, mid+1, right, temp)
  
  // 3. 剪枝优化：如果左半部最大值 <= 右半部最小值，说明整个 [left, right] 已经有序，无需合并
  if arr[mid] <= arr[mid+1] {
    return
  }

  // 4. 双指针初始化：
  // i 遍历左半区间 [left, mid]，j 遍历右半区间 [mid+1, right]，k 指向 temp 写入位置
  i, j, k := left, mid+1, left
  // 双指针比较：按升序依次将较小值填入 temp
  // 注：若写为 arr[i] <= arr[j]，可保证排序算法的稳定性（Stable Sort）

  for i <= mid && j <= right {
    if arr[i] <= arr[j] {
      temp[k] = arr[i]
      i++
    } else {
      temp[k] = arr[j]
      j++
    }
    k++
  }
  // 5. 收尾：将左半区间剩余的元素按序拷入 temp
  for i <= mid {
    temp[k] = arr[i]
    i++
    k++
  }
  
  // 6. 收尾：将右半区间剩余的元素按序拷入 temp
  for j <= right {
    temp[k] = arr[j]
    j++
    k++
  }
  
  // 7. 回写：将本次在 temp 中排好序的 [left, right] 同步回原切片 arr
  for idx := left; idx <= right; idx++ {
    arr[idx] = temp[idx]
  }
}
```


# 快速排序（Quick Sort）

采用分治法（Divide and Conquer）策略。其核心思想是选择一个基准元素（Pivot），通过一趟排序将待排数组划分为两个独立的部分：左侧所有元素小于等于基准值，右侧所有元素大于等于基准值，然后递归地对这两部分继续进行快速排序。

### 核心步骤与复杂度

1. **挑选基准（Pivot Selection）：** 从数组中选取一个元素作为基准（常见选择首尾元素、中间元素或三数取中）。
    
2. **分区操作（Partitioning）：** 重新排列数组，所有比基准小的元素移到基准左边，所有比基准大的元素移到右边。该操作结束后，基准元素便处于其最终有序的正确位置。
    
3. **递归排序（Recursion）：** 递归地对基准左侧子数组和右侧子数组重复上述步骤，直到子数组长度为 0 或 1。
    

- **时间复杂度：** 平均时间复杂度为 $\mathcal{O}(n \log n)$，最坏情况（如已有序且每次选首尾）为 $\mathcal{O}(n^2)$。
    
- **空间复杂度：** 递归调用栈空间为 $\mathcal{O}(\log n)$ 至 $\mathcal{O}(n)$，属于原地排序算法（In-place）。
    

### Go 语言实现


```go
package main

import "fmt"

// QuickSort 对切片 nums 进行就地快速排序
func QuickSort(nums []int) {
	if len(nums) <= 1 {
		return
	}
	quickSortHelper(nums, 0, len(nums)-1)
}

func quickSortHelper(nums []int, low, high int) {
	if low < high {
		// 获取分区后的基准点索引
		p := partition(nums, low, high)
		// 递归处理左半部分与右半部分
		quickSortHelper(nums, low, p-1)
		quickSortHelper(nums, p+1, high)
	}
}

// partition 采用 Lomuto 分区方案：以最后一个元素为 pivot
func partition(nums []int, low, high int) int {
	// 随机挑一个位置与末尾交换 
	randIdx := low + rand.Intn(high-low+1) 
	nums[randIdx], nums[high] = nums[high], nums[randIdx]

	pivot := nums[high]
	i := low // i 记录小于 pivot 区域的边界右侧

	for j := low; j < high; j++ {
		if nums[j] < pivot {
			nums[i], nums[j] = nums[j], nums[i]
			i++
		}
	}
	// 将基准元素放到最终的正确位置
	nums[i], nums[high] = nums[high], nums[i]
	return i
}

func main() {
	arr := []int{29, 10, 14, 37, 14, 20, 7, 16, 12}
	fmt.Println("排序前:", arr)
	QuickSort(arr)
	fmt.Println("排序后:", arr)
}
```
