
**树（Tree）本质上是“受限的无环连通图”**。

# 1. 核心本质与通俗直觉

- **递归本质**：任何一棵树都是由“根节点 + 若干棵互不相交的子树”组成的。这意味着**几乎所有树类算法天生契合递归（DFS）与分治思想**——处理整棵树的逻辑，完全等同于处理左子树与右子树的逻辑组合。
    
- **分层推进**：树具有天然的深度与层级概念，适合用队列模拟逐层扩散（BFS），常用于解决“最短路径”、“层序视图”、“逐层聚合”等问题。
    
- **高频信号词**：当题目中出现“层级派生”、“最近公共祖先”、“多叉目录结构”、“从根到叶的路径极值”或“完全二叉树数组下标”时，底层的核心模型都是树。
    

# 2. 核心考纲与高频子模型

在编程面试与机考中，树的考查重点高度集中，通常可划分为以下四大高频子模型：

|**子模型**|**核心考察点**|**典型题目 / 考场变体**|
|---|---|---|
|**深度优先遍历 (DFS)**|前/中/后序遍历、自顶向下传参 vs 自底向上汇聚|二叉树最大深度、对称二叉树、翻转二叉树、路径总和|
|**广度优先遍历 (BFS)**|队列维护层级、分层输出、锯齿形遍历|层序遍历、二叉树的右视图、最小深度|
|**树的构建与序列化**|数组/边表还原树、前序+中序还原、层序数组建树|完全二叉树数组模拟、ACM 模式下的父子输入建树|
|**树形动态规划 / LCA**|树上最长路径、状态向上传递、公共祖先查找|二叉树的直径、最近公共祖先 (LCA)、打家劫舍 III|

# 3. 经典例题

### 一、深度优先遍历（DFS）子模型

#### 1. 前序遍历（Pre-order Traversal）

- **标杆题**：**LeetCode 144. 二叉树的前序遍历**（简单）
    
- **考察机制**：根 $\to$ 左 $\to$ 右。常用于需要**自顶向下携带父节点信息/路径状态**的场景。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func preorderTraversal(root *TreeNode) []int {
        var res []int
        var dfs func(node *TreeNode)
        dfs = func(node *TreeNode) {
            if node == nil { return }
            res = append(res, node.Val) // 根
            dfs(node.Left)              // 左
            dfs(node.Right)             // 右
        }
        dfs(root)
        return res
    }
    ```

**LeetCode 112 路径总和**

自顶向下减去路径值，无需闭包与全局变量

```Go
func hasPathSum(root *TreeNode, targetSum int) bool {
    if root == nil {
        return false
    }

    // 到达叶子节点，检查剩余的 targetSum 是否刚好等于当前节点的值
    if root.Left == nil && root.Right == nil {
        return targetSum == root.Val
    }

    // 递归检查左右子树，只要有一条路径满足即可
    return hasPathSum(root.Left, targetSum-root.Val) || 
           hasPathSum(root.Right, targetSum-root.Val)
}
```

#### 2. 中序遍历（In-order Traversal）

- **标杆题**：**LeetCode 98. 验证二叉搜索树**（中等）
    
- **考察机制**：左 $\to$ 根 $\to$ 右。**二叉搜索树（BST）的中序遍历序列严格单调递增**，考察能否利用该性质做动态合法性校验或寻找第 K 小元素（LeetCode 230）。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func isValidBST(root *TreeNode) bool {
        prev := math.MinInt64
        var inOrder func(node *TreeNode) bool
        inOrder = func(node *TreeNode) bool {
            if node == nil { return true }
            if !inOrder(node.Left) { return false }
            if node.Val <= prev { return false } // 必须严格递增
            prev = node.Val
            return inOrder(node.Right)
        }
        return inOrder(root)
    }
    ```
    

#### 3. 后序遍历（Post-order Traversal）

- **标杆题**：**LeetCode 104. 二叉树的最大深度**（简单）
    
- **考察机制**：左 $\to$ 右 $\to$ 根。常用于**自底向上收集子节点信息并汇总**（如深度、节点数、子树合法性等），是分治思想的核心载体。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func maxDepth(root *TreeNode) int {
        if root == nil { return 0 }
        left := maxDepth(root.Left)
        right := maxDepth(root.Right)
        return max(left, right) + 1 // 汇总子树深度
    }
    ```
    

#### 4. 自顶向下传参（Top-down Accumulation）

- **标杆题**：**LeetCode 112. 路径总和**（简单）
    
- **考察机制**：父节点将剩余目标值或累计路径自顶向下传递给子节点，在叶子节点处做断言判断。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func hasPathSum(root *TreeNode, targetSum int) bool {
        if root == nil { return false }
        if root.Left == nil && root.Right == nil {
            return targetSum == root.Val
        }
        return hasPathSum(root.Left, targetSum-root.Val) || 
               hasPathSum(root.Right, targetSum-root.Val)
    }
    ```
    

#### 5. 自底向上汇聚（Bottom-up Aggregation）

- **标杆题**：**LeetCode 101. 对称二叉树**（简单）
    
- **考察机制**：将子问题分解到左子树与右子树，两两比较或两两归并后向上传递布尔值或计算结果。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func isSymmetric(root *TreeNode) bool {
        if root == nil { return true }
        var check func(p, q *TreeNode) bool
        check = func(p, q *TreeNode) bool {
            if p == nil && q == nil { return true }
            if p == nil || q == nil || p.Val != q.Val { return false }
            return check(p.Left, q.Right) && check(p.Right, q.Left) // 外侧与内侧分别对称
        }
        return check(root.Left, root.Right)
    }
    ```
    

### 二、广度优先遍历（BFS）子模型

#### 1. 基础分层输出（Level-by-level Traversal）

- **标杆题**：**LeetCode 102. 二叉树的层序遍历**（中等）
    
- **考察机制**：利用 `levelSize := len(queue)` 锁定当前层的元素数量，将该层节点一次性全部弹出并存入子数组中。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func levelOrder(root *TreeNode) [][]int {
        if root == nil { return nil }
        var res [][]int
        q := []*TreeNode{root}
        for len(q) > 0 {
            size := len(q)
            level := make([]int, size)
            for i := 0; i < size; i++ {
                node := q[0]
                q = q[1:]
                level[i] = node.Val
                if node.Left != nil { q = append(q, node.Left) }
                if node.Right != nil { q = append(q, node.Right) }
            }
            res = append(res, level)
        }
        return res
    }
    ```
    

#### 2. 层序视图（Layer View / 投影截取）

- **标杆题**：**LeetCode 199. 二叉树的右视图**（中等）
    
- **考察机制**：在层序遍历每一层推进时，抓取该层的最后一个元素（即 `i == size-1`）加入结果集。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func rightSideView(root *TreeNode) []int {
        if root == nil { return nil }
        var res []int
        q := []*TreeNode{root}
        for len(q) > 0 {
            size := len(q)
            for i := 0; i < size; i++ {
                node := q[0]
                q = q[1:]
                if i == size-1 { res = append(res, node.Val) } // 每层最右侧节点
                if node.Left != nil { q = append(q, node.Left) }
                if node.Right != nil { q = append(q, node.Right) }
            }
        }
        return res
    }
    ```
    

#### 3. 锯齿形 / Z字形遍历（Zigzag Traversal）

- **标杆题**：**LeetCode 103. 二叉树的锯齿形层序遍历**（中等）
    
- **考察机制**：维持普通 BFS 队列顺序入队，但在将元素填入本层数组时，利用方向标志位控制“从左向右”还是“从右向左”写入。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func zigzagLevelOrder(root *TreeNode) [][]int {
        if root == nil { return nil }
        var res [][]int
        q := []*TreeNode{root}
        leftToRight := true
        for len(q) > 0 {
            size := len(q)
            level := make([]int, size)
            for i := 0; i < size; i++ {
                node := q[0]
                q = q[1:]
                idx := i
                if !leftToRight { idx = size - 1 - i } // 逆序填充
                level[idx] = node.Val
                if node.Left != nil { q = append(q, node.Left) }
                if node.Right != nil { q = append(q, node.Right) }
            }
            leftToRight = !leftToRight
            res = append(res, level)
        }
        return res
    }
    ```
    

### 三、树的构建与序列化子模型

#### 1. 前序 + 中序还原二叉树（Divide & Conquer Reconstruction）

- **标杆题**：**LeetCode 105. 从前序与中序遍历序列构造二叉树**（中等）
    
- **考察机制**：前序首节点定根，在中序中定位根节点划分出“左子树区间”与“右子树区间”，配合哈希表快速定位中序根索引，递归分治构建。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func buildTree(preorder []int, inorder []int) *TreeNode {
        inPos := make(map[int]int, len(inorder))
        for i, v := range inorder { inPos[v] = i }
    
        var build func(pStart, pEnd, iStart, iEnd int) *TreeNode
        build = func(pStart, pEnd, iStart, iEnd int) *TreeNode {
            if pStart > pEnd { return nil }
            rootVal := preorder[pStart]
            root := &TreeNode{Val: rootVal}
            mid := inPos[rootVal]
            leftLen := mid - iStart
    
            root.Left = build(pStart+1, pStart+leftLen, iStart, mid-1)
            root.Right = build(pStart+leftLen+1, pEnd, mid+1, iEnd)
            return root
        }
        return build(0, len(preorder)-1, 0, len(inorder)-1)
    }
    ```
    

#### 2. 序列化与反序列化（Serialization & ACM 输入建树）

- **标杆题**：**LeetCode 297. 二叉树的序列化与反序列化**（困难）
    
- **考察机制**：树结构与线性字符串/切片的相互转化。重点在于**对空节点（`null` 或 `#`）的标识与恢复**，也是处理机考输入输出的标准考点。
    
- **Go 极简核心**（前序遍历序列化方案）：
    
    
    
    ```Go
    type Codec struct{}
    func Constructor() Codec { return Codec{} }
    
    // 序列化：前序遍历输出带逗号分隔的字符串
    func (c *Codec) serialize(root *TreeNode) string {
        if root == nil { return "#" }
        return strconv.Itoa(root.Val) + "," + c.serialize(root.Left) + "," + c.serialize(root.Right)
    }
    
    // 反序列化：按逗号切分后递归弹出首元素恢复
    func (c *Codec) deserialize(data string) *TreeNode {
        nodes := strings.Split(data, ",")
        var build func() *TreeNode
        build = func() *TreeNode {
            val := nodes[0]
            nodes = nodes[1:]
            if val == "#" { return nil }
            v, _ := strconv.Atoi(val)
            return &TreeNode{Val: v, Left: build(), Right: build()}
        }
        return build()
    }
    ```
    

### 四、树形动态规划与 LCA 子模型

#### 1. 二叉树的最近公共祖先（LCA）

- **标杆题**：**LeetCode 236. 二叉树的最近公共祖先**（中等）
    
- **考察机制**：双向寻找目标节点。若左右两侧均返回非空节点，说明当前节点为最近汇合点；若只有一侧非空，则目标集中在该侧。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
        if root == nil || root == p || root == q { return root }
        left := lowestCommonAncestor(root.Left, p, q)
        right := lowestCommonAncestor(root.Right, p, q)
        if left != nil && right != nil { return root } // 左右两侧均有发现
        if left != nil { return left }
        return right
    }
    ```
    

#### 2. 二叉树的直径（无权路径最值）

- **标杆题**：**LeetCode 543. 二叉树的直径**（简单）
    
- **考察机制**：“单边深度贡献”与“全局拐角最长路径”的分离。递归函数返回给父节点的是**单侧最大深度**，而在遍历途中用 `leftDepth + rightDepth` 持续刷新全局最大直径。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func diameterOfBinaryTree(root *TreeNode) int {
        maxDia := 0
        var depth func(node *TreeNode) int
        depth = func(node *TreeNode) int {
            if node == nil { return 0 }
            l := depth(node.Left)
            r := depth(node.Right)
            maxDia = max(maxDia, l+r) // 经过当前节点的最大路径长度
            return max(l, r) + 1      // 向上返回单侧深度
        }
        depth(root)
        return maxDia
    }
    ```
    

#### 3. 树上最长路径与带权动态规划（树形 DP 终极模型）

- **标杆题**：**LeetCode 124. 二叉树中的最大路径和**（困难）
    
- **考察机制**：节点带正负权值。需注意**负增益舍弃（`max(0, val)`）**，同样遵循“向上返回单侧最大贡献，全局刷新包含拐角的最大路径和”逻辑。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func maxPathSum(root *TreeNode) int {
        maxSum := math.MinInt32
        var maxGain func(node *TreeNode) int
        maxGain = func(node *TreeNode) int {
            if node == nil { return 0 }
            // 负贡献直接剪枝归 0
            leftGain := max(maxGain(node.Left), 0)
            rightGain := max(maxGain(node.Right), 0)
    
            // 刷新包含当前节点作为拐点的全局最大路径和
            maxSum = max(maxSum, node.Val+leftGain+rightGain)
    
            // 只能向父节点返回一条最大延伸分支
            return node.Val + max(leftGain, rightGain)
        }
        maxGain(root)
        return maxSum
    }
    ```
    

#### 4. 树形选择状态机 DP

- **标杆题**：**LeetCode 337. 打家劫舍 III**（中等）
    
- **考察机制**：节点之间存在“选”与“不选”的互斥状态。后序遍历中，每个节点返回一个二元状态 `[rob, notRob]` 向上传递，实现树上无环图的状态转移。
    
- **Go 极简核心**：
    
    
    
    ```Go
    func rob(root *TreeNode) int {
        var dfs func(node *TreeNode) [2]int
        dfs = func(node *TreeNode) [2]int {
            if node == nil { return [2]int{0, 0} }
            left := dfs(node.Left)
            right := dfs(node.Right)
    
            // 选当前节点：左右子节点都不能选
            robCurr := node.Val + left[1] + right[1]
            // 不选当前节点：左右子节点可选可不选，取最大值
            notRobCurr := max(left[0], left[1]) + max(right[0], right[1])
    
            return [2]int{robCurr, notRobCurr}
        }
        res := dfs(root)
        return max(res[0], res[1])
    }
    ```
