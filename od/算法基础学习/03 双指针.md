
**双指针（Two Pointers）** 的核心思想是利用数组或链表的有序性、连续性或结构特征，维护两个游标协同遍历，从而将嵌套循环的 $O(n^2)$ 复杂度压缩到 $O(n)$。

根据指针的移动方向与相对速度，双指针主要分为三大模式：

### 1. 对撞指针（左右指针）

**核心机制：** 两个指针分别置于两端（`left = 0`, `right = n - 1`），根据条件向中间靠拢，直到相遇。通常依赖**数组有序**或**单调性**。

#### 典型题目：LeetCode 167. 两数之和 II - 输入有序数组

> **题意**：给定一个下标从 1 开始的递增整数数组 `numbers`，找到两个数使其和等于目标值 `target`。

- **优化逻辑**：
    
    - 若 `sum == target`，找到解。
        
    - 若 `sum < target`，因数组有序，只有增大较小值才可能达标，故 `left++`。
        
    - 若 `sum > target`，只有减小较大值才可能达标，故 `right--`。
        



```Go
func twoSum(numbers []int, target int) []int {
    left, right := 0, len(numbers)-1
    for left < right {
        sum := numbers[left] + numbers[right]
        if sum == target {
            return []int{left + 1, right + 1}
        } else if sum < target {
            left++
        } else {
            right--
        }
    }
    return nil
}
```

### 2. 快慢指针（同向移动）

**核心机制：** 两个指针从同侧出发（通常从头部），以不同步长或不同触发条件向前移动。常用于**就地去重/修改**与**链表检测**。

#### 典型题目：LeetCode 26. 删除有序数组中的重复项

> **题意**：原地修改升序数组，使每个元素只出现一次，返回去重后的数组新长度。

- **优化逻辑**：
    
    - `slow` 维护当前有效非重复前缀的尾部。
        
    - `fast` 负责向前探路遍历。
        
    - 遇到新元素（`nums[fast] != nums[slow]`）时，`slow++` 并覆盖赋值。
        



```Go
func removeDuplicates(nums []int) int {
    if len(nums) == 0 {
        return 0
    }
    slow := 0
    for fast := 1; fast < len(nums); fast++ {
        if nums[fast] != nums[slow] {
            slow++
            nums[slow] = nums[fast]
        }
    }
    return slow + 1
}
```

### 3. 滑动窗口（变长双指针）

**核心机制：** 双指针围成一个动态区间 `[left, right]`。`right` 扩张纳入新元素，当窗口不满足约束条件时，`left` 收缩直到重新满足，常用于求解最长/最短连续子数组问题。

#### 典型题目：LeetCode 3. 无重复字符的最长子串

> **题意**：找出给定字符串中不含有重复字符的最长子串长度。

- **优化逻辑**：
    
    - 使用哈希表记录字符最新出现的索引。
        
    - 遍历 `right`，若字符已在窗口内出现过，直接将 `left` 跳到该字符上次出现位置的下一位（避免重复）。
        



```Go
func lengthOfLongestSubstring(s string) int {
    lastSeen := make(map[byte]int)
    left, maxLen := 0, 0

    for right := 0; right < len(s); right++ {
        char := s[right]
        if idx, found := lastSeen[char]; found && idx >= left {
            left = idx + 1
        }
        lastSeen[char] = right
        
        curLen := right - left + 1
        if curLen > maxLen {
            maxLen = curLen
        }
    }
    return maxLen
}
```

### 双指针类型对比

|**模式**|**指针初始位置**|**移动策略**|**典型应用场景**|**复杂度**|
|---|---|---|---|---|
|**对撞指针**|两端（`0` 与 `n-1`）|向内相向移动|排序数组求和、回文串验证、盛水容器|时间 $O(n)$，空间 $O(1)$|
|**快慢指针**|同一起点|同向、速度/条件不同|原地修改数组、链表环检测（Floyd）、找链表中点|时间 $O(n)$，空间 $O(1)$|
|**滑动窗口**|同一起点|`right` 扩张，`left` 收缩|满足条件的最长/最短子串或连续子数组|时间 $O(n)$，空间|
