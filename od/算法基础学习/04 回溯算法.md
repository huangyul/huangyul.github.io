
# 回溯算法（Backtracking）核心笔记

回溯算法本质是**带剪枝的深度优先搜索（DFS）**。它在多阶段决策树上逐步向前探索，一旦发现当前路径不满足约束或无法达到最优解，便**撤销当前选择（回溯）**，退回到上一步尝试其他分支。

## 两种核心心智模型对比

|**维度**|**二叉决策树模型（选 / 不选）**|**For 循环模型（多叉决策树）**|
|---|---|---|
|**观察视角**|站在**元素**的角度：“轮到我了，我是被选中还是不选？”|站在**坑位（背包）**的角度：“这里有一个空位，我挑谁放进来？”|
|**分支数量**|固定 2 个分支（选 / 不选、正 / 负）|动态多个分支（循环遍历候选集）|
|**典型应用**|0-1 背包问题、目标和（`+/-`）、分割等和子集|组合总和、全排列、分割回文串、N 皇后|
|**算法演进**|最容易加 `memo` 记忆化，直接推导**动态规划（DP）**|擅长处理复杂的**排列顺序**与**同层/跨层去重**|

## 模型一：二叉决策树（选 / 不选）

每个元素独立经历“选”与“不选”两次递归调用，不需要写 `for` 循环。

### 通用代码模板



```Go
func backtrack(nums []int, index int, currentPath []int, curSum int) {
    // 1. 终止条件：考察完所有元素（注意是 len(nums)，不是 len(nums)-1）
    if index == len(nums) {
        if 满足条件 {
            // 记录答案（必须深拷贝）
        }
        return
    }

    // 分支 1：选择放入 nums[index]
    if 满足剪枝条件 {
        currentPath = append(currentPath, nums[index])  // 做选择
        backtrack(nums, index+1, currentPath, curSum + nums[index]) // 递归深入
        currentPath = currentPath[:len(currentPath)-1]  // 撤销选择（回溯）
    }

    // 分支 2：不选 nums[index]
    backtrack(nums, index+1, currentPath, curSum)
}
```

## 模型二：For 循环（多叉树展开）

用 `for` 循环横向枚举所有可选候选者，用递归纵向深入下一个位置。

- **横向（For 循环）**：在同一层尝试不同候选人。
    
- **纵向（递归深入）**：挑中一个后，去填下一个空位。
    
- **“不选”去哪了？**：弹出当前元素并执行 `i++` 时，本质上就完成了“放弃当前、换下一个”的操作。
    

根据是否受元素顺序影响，分为**组合**与**排列**两种形式：

### 1. 组合 / 子集型（顺序无关，无回头路）

从 `startIndex` 开始循环，下一层传入 `i + 1`，避免选出重复无序组（如避免 `[1, 4]` 和 `[4, 1]` 重复）。



```Go
func backtrack(nums []int, startIndex int, path []int, curSum int) {
    if curSum == target { // 提前剪枝收集
        res = append(res, append([]int(nil), path...))
        return
    }

    for i := startIndex; i < len(nums); i++ {
        if curSum + nums[i] > target { // 剪枝
            continue
        }

        path = append(path, nums[i])
        backtrack(nums, i+1, path, curSum + nums[i]) // 传入 i+1，防止走回头路
        path = path[:len(path)-1]                     // 撤销选择
    }
}
```

### 2. 排列型（顺序相关，需要回头挑）

循环永远从 `0` 开始，使用 `used` 布尔数组记录已被占用的元素。



```Go
func backtrack(nums []int, path []int, used []bool) {
    if len(path) == len(nums) {
        res = append(res, append([]int(nil), path...))
        return
    }

    for i := 0; i < len(nums); i++ { // 每次都从 0 开始扫
        if used[i] { // 剪枝：跳过本轮已用过的元素
            continue
        }

        used[i] = true
        path = append(path, nums[i])

        backtrack(nums, path, used) // 填下一个坑位

        path = path[:len(path)-1]   // 撤销选择
        used[i] = false
    }
}
```

## 面试高频避坑与核心语法

1. **切片结果深拷贝**：
    
    - Go 中切片是指针结构。保存解时切勿直接赋值（`res = append(res, path)` 会导致底层数组被后续回溯篡改）。
        
    - 正确写法：`append([]int(nil), path...)` 或 `slices.Clone(path)`。
        
2. **切片元素出栈（撤销）**：
    
    - 标准回退写法：`path = path[:len(path)-1]`。
        
3. **递归边界判断**：
    
    - 二叉树选/不选模型中，必须考察到 `index == len(nums)`，若写成 `len(nums) - 1` 会直接漏掉最后一个元素的决策。
        
4. **For 循环递归传参**：
    
    - 组合题必须传 `backtrack(i + 1, ...)`；如果错写成 `backtrack(startIndex + 1, ...)` 会导致退化成排列，产生重复组合。
        

## 算法选择速查口诀

- **给每个元素定命运（非此即彼、加减号、是否打包）** $\rightarrow$ **二叉树模型**，方便后续推导动态规划。
    
- **给每个位置挑候选人（从集合里挑一个、考虑顺序、切分字符串）** $\rightarrow$ **For 循环模型**。
