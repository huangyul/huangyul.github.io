# 复杂度分析

## 一、 为什么需要复杂度分析？

* **核心目标**：数据结构与算法解决的是**执行效率（快）**与**存储成本（省）**的问题。
* **事后统计法的局限**：
  * **依赖环境**：不同硬件平台差异巨大。
  * **受数据规模与特征影响**：小规模下插入排序可能比快排更快；数据初始有序度会直接干扰测试结果。
* **渐进复杂度定义**：描述代码执行时间（或空间占用）随**数据规模 $n$** 增长的变化趋势。忽略低阶、常量和系数，只保留最大量级。

---

## 二、 时间复杂度分析法则

* **单段聚焦**：只关注循环/递归执行次数最多的一段核心代码。
* **加法法则（取最大）**：
  $$T(n) = \max(O(f(n)), O(g(n))) = O(\max(f(n), g(n)))$$
* **乘法法则（嵌套乘积）**：
  $$T(n) = O(f(n)) \times O(g(n)) = O(f(n) \times g(n))$$
* **多数据规模**：当存在独立参数 $m$ 和 $n$ 时，加法法则为 $O(m + n)$，乘法法则为 $O(m \times n)$。

---

## 三、 常见时间复杂度量级

| 分类 | 复杂度 | 说明与典型场景 |
| :--- | :--- | :--- |
| **多项式阶** | **$O(1)$** | 常量阶：无随 $n$ 增长的循环或递归 |
| | **$O(\log n)$** | 对数阶：变量按等比变化（对数底数通过换底公式可忽略，统称 $\log n$） |
| | **$O(n)$** | 线性阶：单层循环遍历 |
| | **$O(n \log n)$** | 线性对数阶：如快速排序、归并排序 |
| | **$O(n^2)$** | 平方阶：双重嵌套循环 |
| **非多项式阶 (NP)** | **$O(2^n)$ / $O(n!)$** | 指数阶/阶乘阶：随 $n$ 增大耗时暴增，属于极低效算法 |

---

## 四、 空间复杂度分析
* **定义**：算法的**额外临时存储空间**与数据规模 $n$ 之间的增长关系（渐进空间复杂度）。
* **常见量级**：$O(1)$（常数空间）、$O(n)$（申请长度为 $n$ 的数组/哈希表）、$O(n^2)$。
