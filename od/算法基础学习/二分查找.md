
# 二分查找（Binary Search）

的核心思想非常直观：**在有序数组中，每次将搜索范围缩小一半**。通过比较中间元素与目标值，我们可以果断地丢弃掉不可能包含目标值的那一半区间。

它的时间复杂度是 **O(log n)**，空间复杂度是 **O(1)**（迭代实现）。

---

### 1. 基础二分查找原理

最基础的场景是：**在有序数组中查找目标值，找到返回索引，找不到返回 -1。**

**核心逻辑：**

1. 初始化左右边界 `left = 0`, `right = len(nums) - 1`。
2. 当 `left <= right` 时，计算中间位置 `mid = left + (right - left) / 2`（防止整数溢出）。
3. 比较 `nums[mid]` 与 `target`：
    - 相等：直接返回 `mid`。
    - `nums[mid] < target`：目标在右半部分，`left = mid + 1`。
    - `nums[mid] > target`：目标在左半部分，`right = mid - 1`。

---

### 2. 进阶：处理重复元素（边界二分查找）

当数组中有重复元素时，基础二分可能返回任意一个匹配的位置。实际工程中，我们常需要找**第一个**或**最后一个**出现的位置。

**核心思想：**  
不要一找到目标就立刻返回，而是**继续压缩边界**，直到 `left` 和 `right` 相遇。

#### 场景 A：找第一个出现的位置 (Lower Bound)

- 当 `nums[mid] < target`：`left = mid + 1`
- 当 `nums[mid] >= target`：`right = mid - 1` （**关键：** 即使相等，也继续向左压，但记录当前 `mid` 为潜在答案）

#### 场景 B：找最后一个出现的位置 (Upper Bound)

- 当 `nums[mid] > target`：`right = mid - 1`
- 当 `nums[mid] <= target`：`left = mid + 1` （**关键：** 即使相等，也继续向右压，但记录当前 `mid` 为潜在答案）

---

### 3. Go 语言完整实现

下面是一个包含基础查找、找第一个、找最后一个的完整 Go 实现，并附带了详细的注释和边界处理。



```go
package main

import "fmt"

// 1. 基础二分查找：找到任意一个目标值
func binarySearch(nums []int, target int) int {
	left, right := 0, len(nums)-1
	for left <= right {
		// 防止 (left + right) 溢出
		mid := left + (right-left)/2 
		
		if nums[mid] == target {
			return mid
		} else if nums[mid] < target {
			left = mid + 1
		} else {
			right = mid - 1
		}
	}
	return -1
}

// 2. 找第一个出现的位置 (Lower Bound)
// 如果不存在，返回 -1
func findFirst(nums []int, target int) int {
	left, right := 0, len(nums)-1
	result := -1 // 记录潜在答案

	for left <= right {
		mid := left + (right-left)/2

		if nums[mid] < target {
			left = mid + 1
		} else if nums[mid] > target {
			right = mid - 1
		} else {
			// 找到目标，记录位置，但继续向左搜索
			result = mid 
			right = mid - 1 
		}
	}
	return result
}

// 3. 找最后一个出现的位置 (Upper Bound)
// 如果不存在，返回 -1
func findLast(nums []int, target int) int {
	left, right := 0, len(nums)-1
	result := -1 // 记录潜在答案

	for left <= right {
		mid := left + (right-left)/2

		if nums[mid] > target {
			right = mid - 1
		} else if nums[mid] < target {
			left = mid + 1
		} else {
			// 找到目标，记录位置，但继续向右搜索
			result = mid 
			left = mid + 1 
		}
	}
	return result
}

func main() {
	// 测试数据：包含重复元素
	nums := []int{1, 2, 2, 2, 3, 4, 5, 5, 6}
	target := 2

	fmt.Printf("数组: %v\n", nums)
	fmt.Printf("目标: %d\n", target)
	fmt.Printf("基础查找 (任意索引): %d\n", binarySearch(nums, target))
	fmt.Printf("第一个出现的位置: %d\n", findFirst(nums, target))
	fmt.Printf("最后一个出现的位置: %d\n", findLast(nums, target))

	// 测试不存在的元素
	fmt.Printf("\n目标: 7\n")
	fmt.Printf("第一个出现的位置: %d\n", findFirst(nums, 7))
}
```

### 4. 必须注意的特殊情况与坑

在写二分查找时，90% 的 Bug 来自以下几点：

#### 1. 整数溢出 (Integer Overflow)

- **错误写法：** `mid = (left + right) / 2`
- **风险：** 当 `left` 和 `right` 都很大（接近 `int` 最大值）时，`left + right` 会溢出变成负数。
- **正确写法：** `mid = left + (right - left) / 2`
- **Go 的位运算写法：** `mid = left + (right - left) >> 1` （Go 中 `>>` 优先级低于 `+`，所以不用加括号，但建议加上更清晰）

#### 2. 循环条件：`left <= right` vs `left < right`

- **`left <= right`**：搜索区间是 `[left, right]`，两端都包含。这是最通用的写法，适合**查找具体值**或**找边界**。
- **`left < right`**：搜索区间是 `[left, right)`。通常用于**寻找插入位置**（如 C++ 的 `lower_bound`），循环结束时 `left == right`，该位置即为插入点。
- **建议：** 除非你非常清楚自己在做什么，否则**统一使用 `left <= right`**，逻辑最不容易出错。

#### 3. 边界移动：`mid + 1` 和 `mid - 1`

- 当 `nums[mid] != target` 时，**必须**移动 `+1` 或 `-1`。
- **错误写法：** `left = mid` 或 `right = mid`。
- **后果：** 当 `left` 和 `right` 相邻时（例如 `left=3, right=4`），`mid` 算出来是 3。如果 `nums[3] < target`，执行 `left = mid`，`left` 还是 3，**死循环！**

#### 4. 数组为空

- 在函数入口必须处理：`if len(nums) == 0 { return -1 }`
- 虽然 `left=0, right=-1` 时 `left <= right` 不成立会直接跳过循环，但显式判断更安全，避免后续逻辑误用。

#### 5. 目标值不存在

- 找第一个/最后一个时，如果循环结束 `result` 仍是初始值（-1），说明没找到。
- **不要**假设 `nums[left]` 就是答案，因为 `left` 可能越界，或者 `nums[left]` 根本不等于 `target`。
