
# 栈与单调栈核心复习笔记

## 一、先记住这几个结论

### 普通栈解决什么问题？

看到下面场景：

```text
括号匹配
撤销操作
最近一次操作
DFS
递归模拟
```

想到：

```text
Stack
```

---

### 单调栈解决什么问题？

看到下面关键词：

```text
右边第一个更大
右边第一个更小

左边第一个更大
左边第一个更小

最近更大
最近更小

Next Greater Element
```

想到：

```text
Monotonic Stack
```

---

### 普通栈和单调栈区别

普通栈：

```text
只保证后进先出(LIFO)
```

例如：

```text
[5,2,7,1]
```

完全允许。

---

单调栈：

```text
后进先出
+
保持单调
```

例如单调递减栈：

```text
[8,6,4,2]
```

新元素破坏单调性：

```text
不停弹栈
```

直到恢复单调。

---

### 单调栈最重要的一句话

```text
当前元素就是某些元素一直等待的答案
```

例如：

```text
2 1 5
```

当看到 5：

```text
5 > 1
5 > 2
```

于是：

```text
1 找到答案
2 找到答案
```

直接弹出。

---

### 为什么单调栈是 O(n)

每个元素：

```text
最多入栈一次
最多出栈一次
```

所以：

```text
O(n)
```

这是面试高频考点。

---

## 二、LeetCode 20：有效的括号

### 题目

```text
()
()[]{}
([{}])
```

返回：

```text
true
```

---

### 核心思想

遇到左括号：

```text
入栈
```

遇到右括号：

```text
检查栈顶
```

因为：

```text
最近出现且未匹配的左括号
```

一定在栈顶。

这正是：

```text
后进先出
```

---

### 示例

```text
([{}])
```

过程：

```text
(
入栈

([
入栈

([{
入栈

}
匹配 {

]
匹配 [

)
匹配 (
```

最后：

```text
栈为空
```

返回：

```text
true
```

---

### Go模板

```go
stack := []byte{}

for i := 0; i < len(s); i++ {

    if s[i] 是左括号 {
        入栈
    } else {

        if 栈为空 {
            return false
        }

        if 栈顶不匹配 {
            return false
        }

        弹栈
    }
}

return 栈为空
```

---

### 必记点

```text
左括号入栈

右括号检查栈顶

最后栈必须为空
```

## 三、LeetCode 155：最小栈

### 题目

支持：

```text
push()
pop()
top()
getMin()
```

要求：

```text
getMin()
时间复杂度 O(1)
```

---

### 普通做法的问题

例如：

```text
[5,3,7,2]
```

求最小值：

```text
遍历
```

复杂度：

```text
O(n)
```

不符合要求。

---

### 核心思想

维护两个栈：

```text
stack
minStack
```

---

例如：

push(5)

```text
stack:
[5]

minStack:
[5]
```

---

push(3)

```text
stack:
[5,3]

minStack:
[5,3]
```

---

push(7)

```text
stack:
[5,3,7]

minStack:
[5,3,3]
```

---

push(2)

```text
stack:
[5,3,7,2]

minStack:
[5,3,3,2]
```

---

### 为什么可行

minStack每一层记录：

```text
到当前位置为止
最小值是多少
```

因此：

```text
getMin()
```

直接：

```go
minStack[len(minStack)-1]
```

即可。

---

### 必记点

```text
两个栈

stack     存真实数据

minStack  存当前最小值
```

这是辅助栈思想的经典题。

## 四、LeetCode 739：每日温度

### 题目

```text
[73,74,75,71,69,72,76,73]
```

求：

```text
距离右边第一个更高温度还有几天
```

结果：

```text
[1,1,4,2,1,1,0,0]
```

---

### 题目翻译

实际上在问：

```text
右边第一个更大的元素
```

所以：

```text
单调栈
```

---

### 为什么要用单调栈

例如：

```text
75
```

后面：

```text
71
69
72
76
```

需要找到：

```text
76
```

暴力：

```text
每个元素向后搜索
```

复杂度：

```text
O(n²)
```

---

### 单调栈思路

维护：

```text
单调递减栈
```

存：

```text
下标
```

不是温度。

---

遍历：

```text
73
```

栈：

```text
[73]
```

---

看到：

```text
74
```

发现：

```text
74 > 73
```

说明：

```text
73 的答案找到了
```

所以：

```text
73 出栈
```

记录：

```text
1天
```

---

看到：

```text
75
```

发现：

```text
75 > 74
```

所以：

```text
74 出栈
```

记录：

```text
1天
```

---

看到：

```text
72
```

发现：

```text
72 > 69
72 > 71
```

所以：

```text
69 出栈
71 出栈
```

同时得到答案。

---

### 为什么存下标

因为题目要求：

```text
等待几天
```

需要计算：

```go
当前下标 - 原下标
```

所以必须存：

```text
index
```

---

### Go核心模板

```go
for i := 0; i < n; i++ {

    for len(stack) > 0 &&
        nums[i] > nums[stack[len(stack)-1]] {

        j := stack[len(stack)-1]

        stack = stack[:len(stack)-1]

        ans[j] = i - j
    }

    stack = append(stack, i)
}
```

---

### 必记点

```text
右边第一个更大

→ 单调递减栈

栈里存下标

当前元素比栈顶大

→ 栈顶找到答案
→ 弹栈
```
