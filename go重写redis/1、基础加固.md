# Runtime

> [!一句话总结]
程序的运行环境

**特点** ：
- 没有虚拟机的概念
- 作为程序的一部分打包进二进制产物
- 随用户程序一起运行
- 与用户程序没有明显界限，直接通过函数调用
- 有一定屏蔽系统调用的能力，所以可以打包到各个运行环境
- `go` 的关键字都是调用 `runtime` 的函数

**能力** ：
- 内存管理能力
- 垃圾回收能力（GC）
- 并发（携程调度）

# `go` 程序的编译过程

1. 语法分析：
	1. 将源代码翻译成 `Token` 
	2. `Token` 是代码中的最小语义结构
2. 句法分析：
	1. `Token` 序列经过处理，生成抽象语法树(`AST`)
3. 语义分析
	1. 类型检查
	2. 类型判断
	3. 查看类型是否匹配
	4. 函数调用内联
	5. 逃逸分析
4. 中间码生成（`SSA`）
	1. 处理不同平台的差异
	2. 查看从代码生成SSA中间过程：`$env:GOSSAFUNC="main"  export GOSSAFUNC=main`
5. 机器码生成
	1. 先生成 `Plan9` 汇编代码
	2. 编译为机器码
	3. 查看 `Plan9` 汇编代码：`go build -gcflags -S main.go`
6. 链接：将各个包进行链接，包括 `runtime`
