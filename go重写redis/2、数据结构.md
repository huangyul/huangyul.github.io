# 0字节的变量

>[!TIP]
>查看某个变量的字节长度的方法：`unsafe.Sizeof(int(10))`

空结构体：
1. 字节长度为0，也就是不占内存；
2. 地址都是一样的（由runtime包定义的地址）；
3. 主要是为了节约内存。

```go
type K struct {  
}  
  
func main() {  
    k := K{}  
    b := K{}  
    fmt.Println(unsafe.Sizeof(k)) // 0 占字节长度是0  
    fmt.Println(&k == &b)         // true 空结构体的地址是相同的  
  
    // 空结构体的意义：  
    // 1. 结合map实现hashset  
    m := map[string]struct{}{}  
    m["a"] = struct{}{}  
    // 2. 结合channel  
    _ = make(chan struct{})  
}
```
# 字符串的底层

## 所有字符串变量底层都是一个结构体

```go
type stringStruct struct {  
    str unsafe.Pointer  
    len int  
}
```
所以字节长度是**16**
## 字符串使用`utf-8`编码

```go
s := "hello world你好"  
fmt.Println(len(s)) // 17 11+6
```
## 字符串遍历

```go
func main() {  
    s := "hello world你好"  
    for i := 0; i < len(s); i++ {  
       fmt.Println(s[i]) // 会输出ASCII  
    }  
    fmt.Println("------------")  
    for _, i := range s {  
       fmt.Println(string(i)) // 输出单个字符  
    }  
    fmt.Println("------------")  
	fmt.Println(utf8.RuneCountInString(s)) // 获取字符串的真实长度
}
```
关于`for...range...`遍历，遍历出来的是rune类型的字符，但是使用可以**智能**转为字符串
