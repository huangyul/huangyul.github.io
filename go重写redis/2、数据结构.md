# 0字节的变量

>[!TIP]
>查看某个变量的字节长度的方法：`unsafe.Sizeof(int(10))`

空结构体：
1. 字节长度为0，也就是不占内存；
2. 地址都是一样的（由runtime包定义的地址）；
3. 主要是为了节约内存。

```go
type K struct {  
}  
  
func main() {  
    k := K{}  
    b := K{}  
    fmt.Println(unsafe.Sizeof(k)) // 0 占字节长度是0  
    fmt.Println(&k == &b)         // true 空结构体的地址是相同的  
  
    // 空结构体的意义：  
    // 1. 结合map实现hashset  
    m := map[string]struct{}{}  
    m["a"] = struct{}{}  
    // 2. 结合channel  
    _ = make(chan struct{})  
}
```
