# Casbin

`casbin`是一个强大、高效的访问控制库，支持多种访问控制模型，如`ACL/RBAC/ABAC`等。同时支持多种编程语言。

权限实际上就是控制**谁**能对**什么资源**进行**什么操作**。`casbin`将文芳控制模型抽象到一个基于`PERM`（Policy，Effect，Request，Matchers）元模型的配置文件中：
- `policy`是策略的定义，定义了具体的规则。
- `request`是对访问请求的抽象。
- `matcher`匹配器，将请求与定义的`policy`一一匹配，生成多个匹配结果。
- `effect`根据请求运用匹配器得出所有的结果进行汇总，决定该请求是**允许**还是**拒绝**。

## 模型文件

```model
[request_definition]
r = sub, obj, act

[policy_definition]
p = sub, obj, act

[matchers]
m = r.sub == p.sub && r.obj == p.obj && r.act == p.act

[policy_effect]
e = some(where (p.eft == allow))
```
