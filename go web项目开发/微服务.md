# grpc

## proto 文件

简单的protp文件模板如下:
```proto
syntax = "proto3";
package "user.v1";
option go_package = "user/v1;userv1";

service UserService {
	rpc GetUser(Req) returns (Resp)
}

Message Req {
	int64 id = 1;
}

Message Resp {
	string username = 1;
}
```
说明点:
- syntax：指明版本号，现在一般都是用3;
- option go_package：前面是文件的路径，后面是go的package;

详细的proto可参考：[官方中文文档](https://protobuf.com.cn/)

## 编译proto文件

### Buf

`Buf` 是一款更高效、开发者友好的 `Protobuf API` 管理工具，不仅支持代码生成，还支持插件和 `Protobuf` 格式化。

#### 安装

如果是macos，使用brew安装
```shell
brew install bufbuild/buf/buf
```

查看是否安装成功

```shell
buf --help
```
#### 使用Buf生成go代码

##### 初始化配置

```shell
buf config init
```

该命令会在根路径下生成一个 `y` 文件
