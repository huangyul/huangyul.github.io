```csharp
// QueryString是指get方法提交的数据格式如："?User=tom&Psw=123456"
// Body指http请求的body数据
// BusyTime 为请求时间
// ApiKey = "SR-D2882CAC-5CB0-4F0D-B30E-5E7853FED1D4"

Header.Add("BusyTime",BusyTime);
```

## 过滤条件结构FilterModel

>FilterModel

| **参数名** | **参数类型**                 | **必填** | **描述**                                                     |
| ---------- | ---------------------------- | -------- | ------------------------------------------------------------ |
| Operator   | string                       | 否       | in/eq/contain/between                                        |
| Values     | object[]                     | 否       | 值，固定为数组类型<br>空数据表示不传值：[]<br>in可传多个值：["A","B","C"]<br>eq/contain只传一个值：[0]<br>between需传一对值：["2023-9-1","2023-9-2"] |
| DictValue  | Dictionary<string, object[]> | 否       | 字典类型的值<br />如一个标签对应多个标签值, 标签AND，标签值OR，忽略Operator和Value |
