# 大模型

## 概念

从本质上讲，大模型（LLM）是一个**基于 Transformer 架构、拥有海量参数，通过在超大规模文本上进行自监督学习，从而获得了‘涌现能力’和泛化能力的概率预测模型**

## Transform

一种**基于‘自注意力机制（Self-Attention）’的深度学习架构**。
它的特点是：
- 支持超大规模的“并行计算”
- “自注意力机制”能精准捕捉长距离联系
作用：理清**上下文窗口**中的各种提示词、历史聊天记录以及RAG知识库等的逻辑并给出准确的指令

## 分类

### 按模态

- 语言大模型（LLM）：输入文本，输出文本
- 多模态模型：输入可以是文本、图片等；输出也可以是文本、图片等

> 注意：在目前的 Agent 工程实践中，我们通常把 LLM 当作**‘通用多模态推理引擎’**的代名词。因为现在的 LLM 底层早已进化成了 **MLLM（多模态大模型）**

### 按功能

- 生成模型：根据上下文生成文本结果的 LLM，例如GPT等
- 嵌入模型：嵌入模型不负责生成文本，而是把文本或图像映射为向量表示
- 重排序模型：重排序模型会对初步检索到的候选结果重新打分和排序
- 分类模型：分类模型负责把输入归到预定义类别里

**关系对比：**

| 维度       | 大语言模型 / 生成模型（LLM） | 嵌入模型（Embedding） | 重排序模型（Reranker） | 分类模型（Classifier） |
| -------- | ----------------- | --------------- | --------------- | ---------------- |
| **核心任务** | 内容生成              | 语义编码            | 相关性排序           | 类别预测             |
| **输出形式** | 自然语言 / 多模态        | 高维向量            | 相关性分数           | 类别标签             |
| **典型位置** | 最终回答 / 决策         | 检索前处理           | 检索后精排           | 过滤 / 路由 / 标注     |
# 提示词工程

在使用大模型时，通过系统地**设计、组织、测试和优化 Prompt**，让模型在特定任务、约束和上下文下，尽可能稳定地产出符合目标的结果。

- 上下文（Context）：通常指模型在当前这次生成时可直接访问并用于推理的信息集合。
- 上下文窗口：大模型一次最多能处理多长的上下文，是由模型架构和训练决定的，这个长度就是**上下文窗口**。

> **提示词工程**，本质上是**通过系统化地设计、优化输入指令，来引导大语言模型（LLM）准确、稳定地输出预期结果的技术与方法论**。
> 
> 在 AI Agent 开发中，提示词不只是“一句话”，而是**Agent 的“系统指令（System Instructions）”与“行为规范”**，相当于给 AI 写一份高度精确的“岗前培训与工作手册”。

### 在 Agent 开发中的 3 个核心要素

1. **角色与设定（Persona & Goal）：** 明确 Agent 是谁、解决什么问题、输出边界在哪里（比如“你是一个 Python 代码审计专家…”）。
    
2. **上下文与结构（Context & Constraints）：** 规范输入输出格式（如 JSON、XML），明确思维链（CoT），并定义何时调用工具（Tool Calling）。
    
3. **稳定性与控温（Control & Robustness）：** 通过 Few-Shot（少样本提示）、负向约束（拒绝兜底策略）以及防 Prompt 注入（Security Prompting），保证 Agent 在复杂业务场景下的鲁棒性。

# RAG

## RAG是什么

RAG（Retrieval-Augmented Generation，检索增强生成）是一种把 **信息检索** 与 **大模型生成** 结合起来的应用架构。可以理解为给`llm`外挂知识大脑，**在运行时给模型补充它当前需要的上下文**

它的核心思路并不复杂：

1. 用户先提问。
2. 系统先去外部知识源里找相关资料。
3. 把“问题 + 资料”一起发给大模型。
4. 由大模型基于这些资料生成答案。

再说得更工程化一点：

- **Retrieval（检索）**：先找到和问题最相关的资料片段。
- **Augmented（增强）**：把检索到的资料拼进当前 Prompt 或消息上下文。
- **Generation（生成）**：让大模型基于这些资料生成最终答案。

为了解决的问题：

- **知识冻结**：模型训练完成后，知识并不会自动随现实世界更新。
- **私有知识缺失**：企业制度、内部文档、项目资料、课程讲义这类内容，模型训练时通常没见过。
- **幻觉与不可追溯**：模型没把握时容易“猜一个像样答案”，而且很难告诉你依据来自哪里。
