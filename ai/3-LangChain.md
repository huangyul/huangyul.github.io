# LangChain

## 一、LangChain 简介

> [!TIP]
> **LangChain** 是一个 **开源** 的 **大语言模型 (LLM) 应用开发框架**，由哈尔·哈伯梅尔（Harrison Chase）于2022年创建，旨在帮助开发者利用大模型构建端到端、具有上下文感知、可记忆、可规划、可调用外部工具的复杂应用。

LangChain 的核心设计哲学是 **“组件化”** 与 **“可编排”**：它提供了一套标准的接口和组件，让开发者无需陷入繁琐的底层细节（如 API 封装、状态管理、提示词工程、工具集成等），而是能像搭积木一样快速组合出功能完备的 LLM 应用。

LangChain 的 **“Lang”** 指的是 **Language Model（大语言模型）**，**“Chain”** 指的是 **Chain of Thought（思维链）** 或 **“链式调用”** —— 代表着通过将多个组件按一定顺序连接起来，构建出能完成复杂任务的 **完整流程**。

LangChain 已经成长为 LLM 开发领域的 **事实标准** 和 **生态核心**，被广泛用于构建：

- 智能问答助手
- 自动化业务流程
- 代码生成
- 数据分析与报告生成
- Agentic（智能体）系统
- RAG（检索增强生成）应用
- 等等
